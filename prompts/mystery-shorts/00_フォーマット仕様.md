## 2. 三層構造

```
┌─ フック（0〜5秒）────────────────────┐
│  タイトルカード1枚。静止画＋ゆっくりズームイン。   │
│  「〈煽り形容〉＋〈対象〉＋ N選」                │
├─ 本編（5〜80秒）────────────────────┤
│  項目1  … ナンバーカード → 4〜8カット → 余韻    │
│  項目2  … 同上                                │
│  項目3  … 同上（いちばん強いネタを最後に置く）    │
├─ 引き（残り3〜8秒）──────────────────┤
│  謎を解決せずに終わる ／ 次回煽り ／ フォロー導線  │
└──────────────────────────────┘
```

1項目あたり **20〜25秒**。3選なら 5＋25×3＋5 ＝ 85秒。

## 3. タイトル（フック）の型

実測された6本すべてがこの型:

> **〈否定・不可能・禁忌の形容〉＋〈具体的な対象名詞〉＋〈N選〉**

| 実例 | 形容パート | 対象パート | N |
|---|---|---|---|
| 永遠に破れない / ギネス記録 / 4選 | 永遠に破れない | ギネス記録 | 4 |
| 否定されていない / 恐ろしい仮説 / 3選 | 否定されていない | 恐ろしい仮説 | 3 |
| できれば知りたくなかった / 世界の仮説 | できれば知りたくなかった | 世界の仮説 | ― |
| 人類が一度滅んだ / 証拠 / 3選 | 人類が一度滅んだ | 証拠 | 3 |
| 現代科学が説明不能な / 日本の異常空間 / 3選 | 現代科学が説明不能な | 日本の異常空間 | 3 |
| 恐ろしい程不気味な / 偶然の一致 / 3選 | 恐ろしい程不気味な | 偶然の一致 | 3 |

**使い回せる形容パート**
```
現代科学が説明不能な ／ いまだに否定されていない ／ 永遠に破れない
できれば知りたくなかった ／ 教科書には載らない ／ 未だに解明されていない
存在してはいけない ／ 記録から消された ／ 見つかってはいけなかった
恐ろしい程不気味な ／ 誰も説明できない ／ 公式には無かったことになっている
```

**N は 3 が基本、ネタが短い回のみ 4。** 5以上は1項目あたりが薄くなるので使わない。

## 4. テロップ（字幕）仕様

参考動画で完全に共通していた要素:

| 項目 | 仕様 |
|---|---|
| 位置 | 画面中央〜やや下（縦位置 55〜65%）。UIに隠れる下部20%は避ける |
| 行数 | **2行**（短い節のみ1行） |
| 1行の文字数 | **8〜14文字**。ここを超えると縦画面で読めない |
| 表示時間 | 2.0〜3.5秒。ナレーションと完全同期 |
| フォント | 太めの日本語ゴシック（源ノ角ゴシック Heavy / ヒラギノ角ゴ W7 / Noto Sans JP Black） |
| 基本色 | 白 |
| 縁取り | 黒 4〜6px ＋ ドロップシャドウ。背景が明るくても必ず読めるように |
| 強調 | **1テロップにつき強調語は1つだけ**。赤 `#FF2A2A` または 黄 `#FFD400` |
| ナンバーカード | 「1.〇〇」全文を赤で。項目の頭に単独で1.5〜2秒 |

**強調に使う語の種類**（実測）
- 数値: `1.8km` `58カ国語` `4500年前` `465m` `500トン` `11m`
- 固有名: `益田岩船` `オッペンハイマー` `ソロユニバース仮説`
- 感情語: `謎` `何者か` `凶◯` `思い出` `この世界が`

> センシティブ語（自◯・凶◯など）は伏せ字にする。実測動画でも `凶◯` と伏せていた。

## 5. 映像素材

構成比の目安: **AI生成画像 70% ／ 実写ストック 20% ／ アーカイブ写真 10%**

| 種類 | 用途 |
|---|---|
| AI生成静止画（シネマティック実写風） | 主力。抽象概念・再現イメージ・存在しない光景 |
| 実写ストック動画 | 実在する場所・現代の風景・人物の動き |
| 白黒/セピアのアーカイブ風写真 | 「過去の記録」を語るパート。信憑性の演出 |
| 図解・古文書・新聞紙面風 | 「文献に記録がある」を語るパート |

**全カットに必ず微速モーションをかける**（静止画のまま置かない）
- 遅いズームイン 100% → 108%（8割はこれ）
- 遅いズームアウト 108% → 100%
- 上下左右のスローパン

**トランジション**
- 基本はハードカット
- 話題の切れ目でクロスフェード 0.3秒
- 衝撃の事実を出す瞬間だけ 白フラッシュ or グリッチ（1本に2〜3回まで）

## 6. ナレーション / 音

| 項目 | 仕様 |
|---|---|
| 声 | 日本語TTS。落ち着いた低めの声、抑揚は控えめ。ドキュメンタリーのナレーター調 |
| 速度 | やや速め（標準の1.05〜1.15倍）。**約8文字/秒** |
| 総文字数 | 85秒なら **600〜680文字** |
| BGM | ダーク・アンビエント／シネマティック・サスペンス。ドラム無しか低いパルスのみ |
| BGM音量 | ナレーションの -18dB 程度。絶対に声を邪魔しない |
| SE | 場面転換のウーシュ、衝撃の事実でのインパクト音（1本に3〜5回） |

## 7. 文体ルール

参考動画のナレーションから抽出:

**必ず守る**
1. **断定しない。** 語尾は「〜とされる」「〜という説だ」「〜と言われている」「〜のではないか」
2. **具体的な数字を毎項目1つ以上入れる。** 数字が信憑性を作る
3. **年号・地名・人名を出す。**「1987年に」「奈良県の丘陵に」「オッペンハイマーは」
4. **1文を短く。** テロップ2行に収まる長さ（15〜28文字）で区切る
5. **項目の最後は解決せず終わる。**「地下にはまだ続きがある可能性がある」「なぜ完成させなかったのかも謎だ」

**避ける**
- 「みなさんこんにちは」等の挨拶（0.5秒でスワイプされる）
- 「いかがでしたか」等の締め
- 自分の感想・意見
- 断定的な陰謀論の主張（後述）

**接続の定型句**
```
しかし ／ ところが ／ さらに ／ 実は ／ 驚くべきことに ／ にもかかわらず
〜だが、その正体は今も分かっていない
これは〈数字〉にのぼる
現代の技術をもってしても〜
```

## 8. 事実の扱い（重要）

このジャンルは仮説・都市伝説・未解明現象を扱うため、**事実と推測の線引きを台本レベルで固定する**。

- 実在する事実（場所・年号・記録）は **確認できたものだけ** 使う
- 解釈・仮説は必ず「〜という説がある」「〜とする研究者もいる」と明示する
- 参考動画も実際にこの書き分けをしており、これが「胡散臭くならない」理由になっている
- 出典が確認できないネタは、台本に `[要確認]` を残して収録前に潰す

このルールは信頼性のためだけでなく、プラットフォームの誤情報ポリシー対策としても機能する。
