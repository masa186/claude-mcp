台本と素材がそろったあとの、組み立て手順書。
参考動画6本から実測した値をそのまま使う。

|---|---|
| 解像度 | 1080 × 1920 |

| セーフエリア | 上 12% / 下 20% は UI に隠れる。ここに要素を置かない |

## テロップのスタイル定義

一度作ってプリセット保存し、全カットに使い回す。

```
フォント     : Noto Sans JP Black（または 源ノ角ゴシック Heavy / ヒラギノ角ゴ W7）
サイズ       : 68〜76px（1080幅基準）
行間         : 1.25
配置         : 中央揃え / 縦位置 58%（画面中央よりわずかに下）
塗り         : #FFFFFF
縁取り       : #000000 / 5px
シャドウ     : 不透明度70% / 距離4px / ぼかし6px
強調色A（赤）: #FF2A2A
強調色B（黄）: #FFD400
```

**強調のルール**
- 1テロップにつき強調は1箇所だけ
- 1本の動画で使う強調色は最大2色まで
- 強調部分だけ縁取りを 6px に太くすると視認性が上がる

**ナンバーカード**
```
テキスト全体 #FF2A2A / サイズ 84px / 表示 1.5〜2.0秒 / 単独カット
表記は「1.〇〇」（半角ピリオド＋スペース無し）
```

## タイトルカード（フック）の組み方

参考動画では、タイトルを**行ごとにサイズと色を変えて**組んでいる。

```
現代科学が          ← 白 / 小さめ（60px）
説明不能な          ← 白 + 紫グロー / 大（88px）
日本の              ← 白 / 小さめ（60px）
異常空間            ← 赤 #FF2A2A / 大（92px）
  3選              ← 金グラデーション / 中（76px）+ 縁取り金
```

ポイント:
- **4〜5行に分割し、行ごとに大小をつける**。1行にベタ打ちすると弱い
- キーワードの行だけ色を変える（赤 or 紫）
- 「N選」は金色グラデーション＋太い縁取りが定番
- 背景は暗く落とす（明度 -30%）か、黒の半透明レイヤーを敷く
- タイトルカードは 3〜5秒 表示。その間もゆっくりズームインさせる

## タイムライン組み立て手順

1. **音を先に置く。** TTSナレーションを1本の音声として書き出し、タイムラインに配置
2. ナレーションの文の切れ目に **マーカーを打つ**
3. マーカーに合わせて画像素材を並べる（1文＝1カット）
4. 各カットに **スケールキーフレーム**を打つ
   - ズームイン：始点 100% → 終点 108%
   - ズームアウト：始点 108% → 終点 100%
   - 全カットにこれをやる。静止画のまま置かない
5. テロップをナレーションに完全同期させる（0.1秒でもズレると気になる）
6. BGMを敷く（ナレーション -18dB）
7. SEと白フラッシュを入れる（1本に3〜5回、「一撃」のカットだけ）
8. 透かし `@アカウント名` を全編に配置（不透明度 15〜25%、中央〜下部）

## トランジションの使い分け

| 種類 | 尺 | 使いどころ | 頻度 |
|---|---|---|---|
| ハードカット | 0 | 基本すべて | 8割 |
| クロスフェード | 0.3秒 | 同じ項目内で場所が変わらないとき | 2割 |
| 白フラッシュ | 0.15秒 | 「一撃」の事実を出す瞬間 | 1本に3〜5回 |
| グリッチ / RGBずれ | 0.2秒 | 項目の切り替わり | 1本に2〜3回 |
| ズームブラー | 0.3秒 | 時代・場所が大きく飛ぶとき | 1本に1〜2回 |

> 参考動画#6 は全編クロスフェードでつないでいた。落ち着いた語り口の回はこの手法もあり。
> ただし1本の中でハードカット主体とディゾルブ主体を混ぜないこと。

## テンポの目安

| 区間 | カット長 |
|---|---|
| タイトルカード | 3.0〜5.0秒 |
| ナンバーカード | 1.5〜2.0秒 |
| 提示・説明パート | 2.0〜2.5秒 |
| 一撃の直前 | 1.2〜1.5秒（詰めて緊張を作る） |
| 一撃 | 2.5〜3.0秒（少し長く止めて見せる） |
| 余韻 | 3.0〜3.5秒 |

**加速して、止める。** これがこのフォーマットのリズム。均等割りにすると単調になる。

---

## 音の作り方

```
ナレーション : -6dB ピーク / コンプレッサーで潰して一定に
BGM          : -24dB（ナレーションの約 -18dB）
SE           : -12dB
```

- ナレーションの下に **軽いローパスをかけたBGM**を敷くと声が抜ける
- 項目の切り替わりで BGM を 0.5秒だけ -30dB まで下げると、ナンバーカードが立つ
- 最後の3秒は BGM をフェードアウトさせず、途中で切る（余韻が残る）
