## 残り26点の生成 ― Higgsfield 以外の選択肢

Higgsfield はフリープランだと生成自体ができない（`job_minimum_basic_plan_required`）。
`generate_rest.py` は APIキーさえあれば以下のどれでも動く。

| サービス | 環境変数 | 9:16 | 備考 |
|---|---|---|---|
| **Google Imagen** | `GEMINI_API_KEY` | ネイティブ対応 | **第一候補。** 縦動画向きで調整不要 |
| OpenAI gpt-image-1 | `OPENAI_API_KEY` | 2:3まで | 書き出し後に 9:16 へ調整が必要 |
| Replicate（FLUX） | `REPLICATE_API_TOKEN` | ネイティブ対応 | 従量課金 |

```bash
export GEMINI_API_KEY=...
python3 generate_rest.py --provider gemini            # 26点まとめて
python3 generate_rest.py --provider gemini --only A01,A27   # 一部だけ
python3 generate_rest.py --provider gemini --dry-run  # 確認だけ
```

生成済みファイルがあるカットは自動でスキップするので、失敗した分だけ再実行できる。

**キーを使わない場合**は `残り26点_画像プロンプト.txt` をそのまま
Midjourney / NijiJourney / ローカルの Stable Diffusion 等に貼れる。
共通スタイルは各行に展開済みなので、コピペだけで絵柄がそろう。

## 素材がそろったあと

1. `素材管理表.csv` の「状態」を全部「完了」にする
2. 全素材に同じ LUT を一括で当てる（これだけで統一感が出る）
3. `../../04_編集テロップ仕様.md` の手順でタイムラインを組む
   - 音を先に置く → マーカー → 素材を並べる → 全カットにズームキーフレーム → テロップ
4. 共用素材（A01/A03/A13/A27/A28）は、同じ画像でも **トリミングとズーム方向を変える**。
   そのまま2回出すと使い回しがバレる
