44カットを重複整理して **35素材** に圧縮した。

| 種別 | 点数 | 状態 |
|---|---|---|
| AI画像 | 32素材 | 未（`generate_rest.py` で生成） |
| 図版（Python生成） | 3ファイル | ✅ 完了 |

## いちばん重要な設計判断：図版は3点しか使わない

参考動画6本を解析した結果、**この系統はデータビジュアルを1カットも使っていない。**
最初から最後まで写真的な絵で構成されている。黒背景のグラフが続くと確実に飽きられる。

図版を当てていいのは、**ナレーションが述べている内容そのものが図であるカット**だけ。

| ファイル | カット | なぜここは図版でいいのか |
|---|---|---|
| `A06_cut06-07_アップスウィープ_スペクトログラム.png` | 6, 7 | 「周波数が上昇していく音が延々と繰り返される」＝上昇掃引そのもの。20→95Hz のチャープ列を合成して STFT にかけた本物 |
| `A26a_cut32_52ヘルツの孤立ピーク.png` | 32 | 「52ヘルツ。」の一拍。ここだけ図で止めると効く |
| `A26b_cut34-35_52ヘルツとシロナガスの帯.png` | 34, 35 | 10〜39Hz の帯と52Hzを並べた比較。「この個体だけ違う」が1枚で伝わる。クジラの絵に一瞬重ねる使い方 |

それ以外の41カットはすべて写真的な絵にする。特に **カット2（0:03）は絶対に図版にしない。**
いちばん離脱が起きる位置なので、指が止まる絵を置くこと。

`render_assets.py --all` を付けると、没にした図版（オシロスコープ・季節変動グラフ・ハム波形・
地球・海図・三波形）も描ける。写真素材がどうしても用意できない場合の保険であって、既定では使わない。

## AI画像32点の生成

Higgsfield はフリープランだと生成自体ができない（`job_minimum_basic_plan_required`）。
`generate_rest.py` は APIキーさえあれば以下のどれでも動く。

| サービス | 環境変数 | 9:16 | 備考 |
|---|---|---|---|
| **Google Imagen** | `GEMINI_API_KEY` | ネイティブ対応 | **第一候補。** 縦動画向きで調整不要 |
| OpenAI gpt-image-1 | `OPENAI_API_KEY` | 2:3まで | 書き出し後に 9:16 へ調整が必要 |
| Replicate（FLUX） | `REPLICATE_API_TOKEN` | ネイティブ対応 | 従量課金 |

```bash
export GEMINI_API_KEY=...
python3 generate_rest.py --provider gemini            # 32点まとめて
python3 generate_rest.py --provider gemini --only A01,A27   # 一部だけ
python3 generate_rest.py --provider gemini --dry-run  # 確認だけ
```

生成済みファイルがあるカットは自動でスキップするので、失敗した分だけ再実行できる。

**キーを使わない場合**は `画像プロンプト_全32点.txt` をそのまま
Midjourney / ローカルの Stable Diffusion 等に貼れる。
共通スタイルは各行に展開済みなので、コピペだけで絵柄がそろう。

### プロンプトに埋め込んである意図

- `negative space in the center of the frame` … 中央はテロップが乗るので必ず空ける
- `no text, no watermark, no letters` … 画面内のAI生成文字はテロップと干渉して読めなくなる
- 赤い光点・赤い経路の類は **画像生成に描かせず編集で足す**（位置と明滅を制御するため）。
  A08（地球）と A30（海図）がこれに該当する

## 素材がそろったあと

1. `素材管理表.csv` の「状態」を全部「完了」にする
2. 全素材に同じ LUT を一括で当てる（これだけで統一感が出る）
3. `../../04_編集テロップ仕様.md` の手順でタイムラインを組む
   - 音を先に置く → マーカー → 素材を並べる → 全カットにズームキーフレーム → テロップ
4. 共用素材（A01/A03/A08/A13/A27/A28）は、同じ画像でも **トリミングとズーム方向を変える**。
   そのまま2回出すと使い回しがバレる
