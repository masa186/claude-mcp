## なぜ短くしたか

1本目（地球の音・敬語・100秒）の実測：

```
視聴を継続      67.2%   ← 冒頭は効いている。触らない
平均視聴時間    45秒
③の開始位置    63秒     ← 一番強いネタに大半が届いていない
```

冒頭は機能していたので、**③が平均視聴時間の近くに来るまで詰める**のが目的。

| | 1本目 | この台本 |
|---|---|---|
| 総尺 | 100秒 | **85秒** |
| カット数 | 46 | **34** |
| 文字数 | 685 | **558** |
| **③の開始** | **63.0秒** | **47.2秒** |

47秒なので平均視聴時間（45秒）をまだ2秒だけ超えている。これ以上詰めると数字か留保を削ることになるので、ここで止めた。
