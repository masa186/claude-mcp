## なぜこれを第1話にしたか

チャンネル名は「broを眠らせない**未解明ファイル**」。電子レンジの仕組みは**解明済み**なので、
1話目に置くと看板と中身がズレる。

飛行機は「学校の説明が間違い」＋「**専門家の間でも説明の仕方が定まっていない**」の二段構え。
看板に合ったうえで、掴みは電子レンジより強い。

| | 電子レンジ | 飛行機 |
|---|---|---|
| 掴み | 食べ物を温めてない | 学校で習ったやつは間違い |
| 終わり方 | 解決する | **決着がついていない** |
| 看板との一致 | ズレる | 合う |

このチャンネルは1本目から**「まだ分かっていない」で終わる**型でやっている。
飛行機はその型に入る。電子レンジは入らないので、2話目（型を1回崩す回）に置く。

## 先に確かめてほしいこと ― 「bro」の読み

**AI読み上げが `bro` を「ビーアールオー」と読む可能性がある。**
そうなると1話の1行目が丸ごと台無しになる。

```
おいbro、飛行機が飛ぶ理由知ってる？
おいブロ、飛行機が飛ぶ理由知ってる？
```

この2行を読ませて聴き比べる。崩れるなら、**読み上げに入れる文字は `ブロ`、
字幕と黒板に出す文字は `bro`** に分ける。音は「ブロ」、画は `bro`。

この台本での該当は1箇所（カット1の冒頭）だけ。

## 事実の出どころ

| | 確度 | 中身 |
|---|---|---|
| 同時到達説は間違い | **[A]** | 上下に分かれた空気が後縁で同時に合流する、という前提が実験で否定されている。上面を通った空気のほうが**先に**着く |
| 平らな翼でも飛ぶ | **[A]** | 紙飛行機、平板。翼の膨らみは揚力の必要条件ではない |
| 背面飛行 | **[A]** | 曲芸機は背面で飛ぶ。左右対称の翼型も多い |
| 空気を下向きに曲げている | **[A]** | ダウンウォッシュ。その反作用が揚力。正しい説明の1つ |
| 揚力は計算できる | **[A]** | 設計段階で予測できる。だから飛行機は飛ぶ |
| 説明の仕方で議論が続いている | **[B]** | 2020年に一般誌が「誰も説明できない」と書いて論争になった。空気力学者からは言い過ぎだという反論も出ている |

**「飛行機がなぜ飛ぶか分かっていない」とは言っていない。** そこは事実ではない。
言っているのは**「計算はできる。説明の仕方が定まっていない」**の2つ。
台本のカット4もその通りに書いてある。ここを盛ると嘘になるので、変えないこと。
