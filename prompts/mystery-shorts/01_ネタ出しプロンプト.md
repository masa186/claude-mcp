# 01. ネタ出しプロンプト

台本を書く前に、当たるテーマとタイトルを量産するためのプロンプト。
出力されたタイトルの中から1つ選び、`02_台本生成プロンプト.md` に渡す。

---

## そのままコピーして使う

```
あなたは日本語のミステリー系ショート動画（TikTok / YouTube Shorts / Instagram Reels）専門の
リサーチャー兼企画者です。1本60〜95秒の縦型動画の企画を出してください。

# 出力してほしいもの
テーマ候補を 15本 出してください。

# タイトルの型（厳守）
「〈否定・不可能・禁忌をあらわす形容〉＋〈具体的な対象名詞〉＋〈3選〉」

使える形容パートの例（そのまま使ってもよいし、同じ温度で新しく作ってもよい）:
  現代科学が説明不能な / いまだに否定されていない / 永遠に破れない /
  できれば知りたくなかった / 教科書には載らない / 未だに解明されていない /
  存在してはいけない / 記録から消された / 公式には無かったことになっている /
  恐ろしい程不気味な / 誰も説明できない

# 各テーマについて、以下を1行ずつ書いてください
1. タイトル（上の型に従う）
2. 3つの項目の見出し（各15文字以内）
3. 最も強いネタ（＝3番目に置くもの）が何かと、その一撃になる数字や固有名詞
4. 使う映像素材の想定（AI生成画像中心 / 実写ストックが必要 / アーカイブ写真が必要）
5. 事実確認レベル：A=史実として確認できる / B=記録はあるが解釈が分かれる / C=都市伝説・出典不明

# 制約
- 3つの項目はすべて「未解決のまま終われる」ものにすること。
  きれいに解決してしまうネタは、この形式では引きが作れないので採用しない。
- 各項目に、テロップで赤字強調できる具体的な数字（距離・重さ・年号・人数など）が
  最低1つ存在すること。無いテーマは出さない。
- レベルCのネタだけで3項目を構成しないこと。最低2項目はAまたはBにする。
- 既に飽和している定番（バミューダ・トライアングル、ツタンカーメンの呪い、
  ノストラダムス）は、新しい切り口が示せる場合のみ可。
- 日本国内ネタと海外ネタを混ぜ、15本のうち5本以上は日本国内ネタにすること。

# ジャンルの配分
以下から満遍なく出してください:
  古代遺跡・オーパーツ / 日本の異常な場所・巨石・地下構造 / 偶然の一致・シンクロニシティ /
  宇宙・フェルミのパラドックス系仮説 / 哲学的仮説（シミュレーション仮説など） /
  ギネス記録・人体の限界 / 消えた人物・未解決事件（センシティブでないもの） /
  失われた技術・古文書
```

---

## 変数を絞りたいとき

上のプロンプトの末尾に足す:

```
# 今回の縛り
- ジャンル：{ジャンル}
- 舞台：{日本国内 / 海外 / 問わない}
- トーン：{恐怖寄り / 知的好奇心寄り / スケール感重視}
- 避けたい要素：{例：心霊・宗教・実在の個人の犯罪}
```

---

## 出力例（イメージ）

```
■ タイトル：現代科学が説明不能な 日本の巨石 3選
  項目1：岩手・巨釜の折石（高さ16m）
  項目2：宮崎・ぐるかけ岩（推定800トン）
  項目3：長野・分杭峠の磁場異常帯 ← 一撃：ゼロ磁場、年間20万人が訪れる
  素材：実写ストック＋AI生成画像
  確認レベル：A / A / B
```
