# 05. 投稿文・ハッシュタグ・シリーズ運用

---

## 投稿文生成プロンプト

```
以下の動画の投稿文（キャプション）を作ってください。

タイトル：{タイトル}
扱った3項目：{項目1} / {項目2} / {項目3}
アカウント名：{@your_account}

# 出力
1. TikTok用キャプション（全角60文字以内 ＋ ハッシュタグ4個）
2. YouTube Shorts用タイトル（全角40文字以内）
3. YouTube Shorts用説明文（3行 ＋ ハッシュタグ）
4. Instagram Reels用キャプション（全角80文字以内 ＋ ハッシュタグ8個）

# ルール
- 1行目は動画タイトルそのまま
- 2行目に「動画内で最も強い数字」を1つだけ置いて煽る
  例：「3つ目の石は、200トンある。」
- 結論はキャプションに書かない。動画を見ないと分からない状態を保つ
- 絵文字は使わない（このジャンルは使わないほうが重く見える）
- 「衝撃」「ヤバい」等の安い煽り語は使わない
- ハッシュタグは日本語タグ中心。英語タグは1〜2個まで
```

---

## ハッシュタグの基本セット

**共通（毎回入れる）**
```
#都市伝説 #ミステリー
```

**ジャンル別で1〜2個足す**
| ジャンル | タグ |
|---|---|
| 古代遺跡・オーパーツ | `#古代文明` `#オーパーツ` `#歴史ミステリー` |
| 日本の異常空間 | `#日本の謎` `#心霊スポット` `#巨石` |
| 偶然の一致 | `#不思議な話` `#シンクロニシティ` `#怖い話` |
| 宇宙・仮説 | `#宇宙の謎` `#仮説` `#フェルミのパラドックス` |
| 哲学的仮説 | `#哲学` `#シミュレーション仮説` |
| ギネス・人体 | `#ギネス記録` `#雑学` `#人間の限界` |

**汎用（1個足す）**
```
#知らないほうがよかった #ゆっくり解説 #豆知識
```

合計 **4〜5個** に収める。10個以上付けると逆にリーチが落ちやすい。

---

## シリーズ化の設計

参考にしたアカウントは全て、同一フォーマットの連投で伸びている。

**やること**
- タイトルの型を絶対に変えない（`〈形容〉＋〈対象〉＋3選`）
- フォント・強調色・テロップ位置・BGMの系統を固定する
- 透かしの位置とデザインを固定する
- サムネ（カバー画像）のレイアウトを固定する
- 同じ「形容パート」を使い回してシリーズ感を出す
  例：「現代科学が説明不能な◯◯ 3選」を10本続ける

**投稿頻度**
- 最低 週3本。同フォーマットの連投がアルゴリズム上いちばん効く
- 1本あたりの制作を分業できるよう、台本→画像→編集を別日にバッチ処理する

**ネタのストック**
- `01_ネタ出しプロンプト.md` を1回回すと15本ぶん出る
- 15本ぶんのタイトルと項目見出しを先にストックしておき、
  制作日には台本生成から始められる状態にする

## 伸びなかったときに疑う順番

1. **フックの1枚目** … タイトルの「形容パート」が弱い。数字や固有名詞を入れて具体化する
2. **最初の3秒** … 挨拶や前置きが入っていないか。1文目で異常性を出せているか
3. **項目3の一撃** … いちばん強いネタが3番目に来ているか
4. **テロップの文字数** … 1行14文字を超えていないか。縦画面で読めているか
5. **カットのテンポ** … 均等割りになっていないか。「加速して止める」ができているか
6. **最後の3秒** … 謎が解決してしまっていないか。引きが残っているか

上から順に潰す。1と2で大半が解決する。
