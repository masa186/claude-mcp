## 制作フロー

```
01 ネタ出し ──→ タイトル15本のストック
      │
      ▼  1本選ぶ
02 台本生成 ──→ カット表（ナレーション／テロップ／画像プロンプト／カメラ）
      │
      ├─→ [要確認] を潰す
      │
      ├─→ ナレーション列 ──→ TTS ──→ 音声ファイル
      ├─→ 画像プロンプト列 ──→ 03 のスタイルを付けて画像生成
      └─→ テロップ列 ──────┐
                            ▼
                    04 編集・テロップ仕様に従って組み立て
                            │
                            ▼
                    05 投稿文・ハッシュタグ ──→ 投稿
```

## 抽出した「型」の要点

このフォーマットが機能している理由は、以下がすべて固定されている点にある。

1. **タイトル** … `〈否定・不可能・禁忌の形容〉＋〈対象〉＋〈3選〉`
2. **構造** … フック5秒 → 1項目25秒×3 → 引き5秒 ＝ 85秒
3. **1項目の内部** … ナンバーカード → 提示 → 異常性 → 一撃 → 余韻（解決させない）
4. **テロップ** … 2行 × 1行8〜14文字、白＋黒縁、強調は1枚に1語だけ（赤 or 黄）
5. **映像** … 全カットに微速ズーム。1.5〜2.5秒/カット。35〜50カット
6. **文体** … 断定しない（`〜とされる`）／毎項目に具体的な数字を入れる
7. **締め** … 謎を解決せずに終わる

このうち **1・4・7 を崩すと一気に別ジャンルの動画になる。** ここは動かさない。

## 事実の扱いについて

このジャンルは仮説や未解明現象を扱うため、台本の各カットに確度ラベル
（`[A]` 史実 / `[B]` 解釈が分かれる / `[C]` 出典不明）を付ける運用にしている。

- `[C]` は必ず「〜という説がある」と本文で明示する
- 出典不明の数字は `[要確認]` を付けて収録前に潰す
- 参考動画も実際にこの書き分けをしており、それが「胡散臭くならない」理由になっている

信頼性のためだけでなく、プラットフォームの誤情報ポリシー対策としても効く。

## 素材の権利について

- 実写ストックは商用利用可のライセンスを確認して使う
- 実在の個人（存命・故人問わず）の顔はAI生成しない。パブリックドメインの
  アーカイブ写真に置き換える
- カット表に「素材URL」「ライセンス」の列を足して記録しておくと、
  収益化のときに後から困らない
