# カワウソと勉強する部屋 — Lo-fi BGM 耐久動画

YouTube の作業用BGM耐久動画。**曲・映像ともにこのリポジトリのスクリプトで生成した完全オリジナル**で、
既存の音源・素材を使っていないため権利申し立ての心配がない。

## 成果物

| ファイル | 内容 |
| --- | --- |
| `out/otter_lofi_loop_24s.mp4` | 映像24秒＋曲のループ素材（確認用・軽い） |
| `out/loop.wav` | 曲のマスター（53.3秒 / 16小節 / 継ぎ目なし） |
| `out/loop_preview.mp3` | 曲の試聴用 |
| `out/still.jpg` | 静止画（サムネイルの下地に使える） |

10分版・1時間版などの長尺は下の手順でその場で書き出す（尺に比例してファイルが大きくなるため、
リポジトリには置いていない。10分でおよそ300MB）。

## 曲について

- 72BPM、Cmaj9 – Am7 – Dm7 – G7 の4小節進行を16小節ぶん
- 音源はすべて Python で合成：FM合成のローズ、サブベース、フィルタードノイズのドラム、オルゴールのメロディ
- テープの揺れ（ワウフラッター）、レコードのノイズ、アルゴリズムリバーブ、ゆるいコンプレッサーで
  lo-fi らしい質感を作っている
- ラウドネスは平均 -14dB 前後。YouTube のノーマライズでほぼそのまま鳴る想定

## 映像について

- 1920×1080 / 24fps / 24秒のシームレスループ
- 動いているもの：頭の上下と傾き、まばたき、鉛筆を持つ手の筆記動作、マグの湯気、窓の雨、
  電飾のまたたき、フィルムグレイン
- すべての周期が24秒を割り切るように設計してあるため、繰り返しても継ぎ目が出ない
- キャラの顔は既存イラストから切り出し、口元だけ描き替えて穏やかな表情にしてある。
  胴体・腕・手・小物はスクリプトで描画

## 作り直し・尺の変更

```bash
pip install pillow numpy scipy
sudo apt-get install -y ffmpeg

python src/music.py                      # 曲 -> out/loop.wav
python src/render.py                     # 映像 -> out/frames/*.jpg（24秒ぶん576枚）
src/encode.sh 600  out/otter_10min.mp4   # 10分
src/encode.sh 3600 out/otter_1h.mp4      # 1時間
src/encode.sh 10800 out/otter_3h.mp4     # 3時間
```

`src/encode.sh` はループ素材を一度だけエンコードし、あとは再エンコードなしで繰り返すので、
尺を伸ばしても書き出し時間はほとんど変わらない。

曲を差し替える場合は `out/loop.wav` を好きな音源に置き換えて `src/encode.sh` を実行する
（継ぎ目なくループする素材にしておくこと）。

## 調整しやすいところ

- `src/scene.py` の `LOOP`：ループの長さ。変えたときは各アニメーションの周期が割り切れるか確認する
- `src/scene.py` の `build_title()`：画面左下のタイトル文字
- `src/music.py` の `CHORDS` / `MELODY`：コード進行とメロディ
- `src/music.py` の `BPM`：テンポ
