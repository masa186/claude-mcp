## 話者の確定（測って出した）

顔カメラの位置（1040×480）と本人確認：

    左上  x 94〜317,  y 0〜140    iShowSpeed
    右上  x 728〜978, y 0〜120    Kai Cenat
    右中  x 764〜978, y 122〜224  ドクタードーナツ

**この録画はドーナツの手元。** だから彼の声だけマイクが近く、
近接効果で低音が乗る。Speed と Kai はブラウザ越しの配信音声で低音が切れる。
その物理的な差で分けた。

    低音 >10%  ドーナツ（手元マイク）
    低音 <10%  Speed か Kai（配信経由）
    Speed と Kai の区別は、顔カメラのどちらが動いたかで決める

## 話の骨 ── ドーナツは観客、視聴者の代弁者

    ドーナツ「何の時間だよ？」
      → カイ「いや、今だろ」
      → ドーナツ「1対1やるの？マジか！」        ← 約束
      → スピード「今ここでやろうぜ」
      → ドーナツ「カイ、今だ！行け！」          ← 煽る（積み上げ）
      → ドーナツ「トーテム使え！」
      → ［無音 9秒］                        ← 天然の溜め
      → 落ちる                              ← 崩壊
      → ドーナツ *爆笑*                      ← 追い打ち
      → エンドロール開始                      ← 決闘は永久にできない
      → ポエムの横で「何言ってんだこいつ」×4     ← 追い打ち2

**視聴者はドーナツの目で見る。** 彼が煽って、彼が笑う。
これがあるから「見ている自分」が中に入れる。
5チャンネルのどれもやっていない形で、こちらの強みになりうる。

## 型 ── SMPクリップ

話者が4種類（ドーナツ・スピード・カイ・ポエム）なので4色が要る。
マインクラフトclips の2色では足りない。
27秒は SMPクリップの最良帯（20〜29秒・再生の中央値914,983回）に入る。

    白   ＝ ドクタードーナツ
    水色 ＝ iShowSpeed
    黄   ＝ Kai Cenat
    緑   ＝ エンドポエムの文
    赤   ＝ 状況説明（*で囲む）

太い黒フチ。影も座布団も付けない（5チャンネルとも使っていなかった）。

## 音

    全体を -11.5 LUFS へ正規化（元は -21.4）
    効果音は2つだけ
      13.0秒（落下）        sound.impact
      16.5秒（エンドロール）  sound.swap
    **無音の区間には何も足さない。** 溜めが消える

## 割り付け（1080×1920）

    0 〜 403px      黄色い極太タイトル（全編固定）
    403 〜 1613px   素材。高さを埋めて左右を切る
    1613 〜 1920px  黒帯（空）

素材が1040×480（2.17:1）。高さ1210pxを埋めると横は2622pxになるので、
中央1080pxだけ残す＝**横の6割を捨てる。**
どこを残すかは場面ごとに変える。

    決闘の場面    中央のゲーム画面
    落下の瞬間    中央のゲーム画面
    爆笑の場面    右中（ドーナツの顔）を寄せる
    ポエムの場面  中央（詩の文字）＋右中（ドーナツ）
