# 日本語版台本 ── エンドラ討伐（ドクタードーナツ観戦）

素材： `Recording_20260901_0223552.mp4` 142.8秒 / 1040x480 / 30.93fps

## 型は SMPクリップ

5チャンネルの実測から選んだ。**この素材にはSMPクリップ型が本命。**

| | 理由 |
|---|---|
| 再生の中央値 803,762（5チャンネル最高） | 単純に一番強い |
| ドクタードーナツが主役の回が31本・中央値873,995 | **向こうの客はドーナツを知っている** |
| 人名を題名に出すと1.42倍 | ドーナツの名前が効く（マインクラフトclipsは0.40倍で逆効果） |
| 4色で話者を分ける | この素材は**ドーナツ・Speed・Kai の3人**が喋る。2色では足りない |
| 上に帯・下に黒帯 | 素材が1040×480の横長多窓。**帯を前提にした型が構造的に合う** |
| 20〜29秒帯が最良（914,983回） | 下の構成がちょうどそこに収まる |

MCクリップ型（キャラ＝固定色）も候補だったが、
**MCクリップは5チャンネルで一番弱い**（中央値64,980・いいね率0.90%）ので採らない。
ただし**ダンスの音ハメだけ**はMCクリップの得意技なので、締めで借りる。

## 素材のどこが使えるか（実測）

    0〜4秒     討伐直前の詰め
    4秒        実績「Free the End」解除 ＝ 討伐確定
    4〜15秒    絶叫・歓声              ← 使う
    15〜120秒  余韻／ポーズ画面（70〜120秒はほぼ静止）  ← 全部捨てる
    120〜143秒 Speedの歌 → Kaiが立って踊る  ← 使う

**105秒ぶんが死んでいる。** 142.8秒の素材から使えるのは約33秒。

## 音 ── 山は自分で足すしかない

|  | ラウドネス | 突出 |
|---|---|---|
| 討伐区間 そのまま | -20.6 | **0.0%** |
| 討伐区間 正規化後 | -11.4 | **0.0%** |
| ダンス区間 そのまま | -21.6 | **0.0%** |
| ダンス区間 正規化後 | -11.3 | **0.0%** |
| フグ事件（1,837万回） | -10.3 | **6.2%** |

**正規化で大きさは直るが、突出は0.0%のまま変わらない。**
無い山は作れない。**討伐の瞬間とダンスの頭に、効果音で一撃を置く。**
`pipeline/sound.py` の `swap()`（実物から測って合成したもの）と
`impact()` `dodon()` を使う。

## 構成（27秒）

    秒        素材        中身
    0.0-1.5   k 4.0秒     実績解除の瞬間から始める。効果音 impact
    1.5-5.0   k 5.5-9.0   Kaiの絶叫、Speedの歓声
    5.0-7.0   k 10.5-12.5 ドーナツ「チャットどこだ？」
    ─ ここで切る（105秒ぶんを飛ばす）
    7.0-9.0   k 125.5     Speedの歌。効果音 swap を切り替えに置く
    9.0-13.0  k 128-132   歓声
    13.0-16.0 k 133-136   ドーナツ「次は何するんだ？」
    16.0-20.0 k 135-139   Speed「やったぞおお！」
    20.0-27.0 k 138-142.8 **Kaiのダンス**。ここに音ハメ。効果音 dodon

**山を後ろに作る。** SMPクリップの歴代1位は37カット中25本が最後の7.5秒。
この構成もダンスの7秒にカットを集める。

## 画面の割り付け（1080×1920）

    0 〜 403px      黄色い極太タイトル（全編固定）
    403 〜 1613px   素材。高さを埋めて左右を切る
    1613 〜 1920px  黒帯（空のまま）
    字幕            y=1250 あたり、中央寄せ

素材が1040×480（2.17:1）なので、高さ1210pxを埋めると横は2622px。
**中央1080pxだけ残す＝横の6割を捨てる。** 多窓のうちどれを残すかは
場面ごとに変える（討伐はゲーム画面、ダンスはKaiのカメラ）。
