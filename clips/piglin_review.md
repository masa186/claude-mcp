## 1. 字幕は、こちらが書いたものより本家に近い

本家の書き方（`docs/smp_writing.md`）と照らすと、**主要な手が4つ入っている。**

### ① 導入が「一文を5枚に割る」形になっている

    これは最も / 簡単な / ピグリンの頭を / ゲットする / 方法です

本家とまったく同じ形。

    ドクタードーナツが / ゴーレムの倒し方を / 配信視聴者に / 見せつけます
    ドパガキの / 心が浄化される / 絶景が / こちら

こちらが書いた「第一の作戦：土の柱」「第二の作戦：石の斧」は
**名札の羅列**でこの形になっていなかった。ここは負けている。

### ② 「(強化版爆弾マン召喚！)」── 括弧＋あだ名

本家の主力の手が2つ同時に入っている。

    括弧 ( )     編集者のツッコミ。「(どけニート村人)」「(抑えきれない笑い)」
    あだ名       鉄ゴーレム→歩く鉄／氷が反社／理論値村人

**帯電クリーパーを「強化版爆弾マン」と呼ぶのは、本家がやっている事そのもの。**
しかも自分で作った言葉になっている。

### ③ 声を擬音で出している

    drrrrrrr ／ Uhhhh〜 ／ nice〜 ／ うーん🤔 ／ バァ↑あん❤

本家も「*こ、こない*」のように声をそのまま字にする。
絵文字も本家が使っている（「いくわ✋」「いっちゃえいっちゃえ♡」）。

### ④ 編集者の声が入っている

    そんな方法あるのか？          ← 視聴者の代弁
    読み込まれてたんだ…？
    これ以上に簡単な方法ある？     ← 締め

**画面の説明ではなく、画面に対して喋っている。**

### 音も悪くない

レンジ12.3はSMPクリップの正常帯（7.1〜17.5）の中。
第12話が3.5で平らだったのと比べると、抑揚がちゃんとある。

## 2. 直したところ（字幕には一切触っていない）

| | 前 | 後 |
|---|---|---|
| 無料編集ソフトの透かし | `clideo.com` が画面の95.5〜98.5%に出続ける | 除去 |
| 消し忘れの英語テロップ | `easy piglin head` が「lin head」と切れて全編出ている | 除去 |
| 死んだ黒帯 | 上0〜12%と下84〜100%＝**画面の28%が黒** | SMPの帯割りに組み直し |
| 固定タイトル | 無し | 黄「一番簡単な方法」を全編固定 |
| 音量 | -20.8LUFS（小さすぎる） | -15.9LUFS |
| 寸法 | 2160×3840 / 60fps（ショートに不要） | 1080×1920 / 30fps |

### 英語テロップは切り落とせなかった

コマで測ると、

    英語テロップの下端  画面の 21.5%
    顔の頭頂            画面の 21.7%

**0.2%（元映像で8px）しか離れていない。**
ここで切ると頭が欠ける。

なので**顔カメラの右側だけを黒で塞いだ**（`pipeline/fixclip.py` の patch）。
顔カメラの右隣はもともと黒い余白なので、塞いでも不自然にならない。

## 3. 直していないところ（編集ソフト側でしか直せない）

### ① 字幕の高さがバラバラ

    これは最も              画面の約52%
    そんな方法あるのか？    約62%
    (強化版爆弾マン召喚！)  約64%
    drrrrrrr                約76%

**本家は高さを固定している。** 目が毎回探しに行くので疲れる。
1か所に決めて、そこから動かさない。

### ② 字幕の大きさがバラバラ

「そんな方法あるのか？」が「これは最も」の半分くらいしかない。
本家は**全部同じ大きさ**で、色で役割を分けている。
小さくすると、スマホでは読めない。

### ③ 尺が30.6秒

252本で数えると

    20〜29秒  914,983回  ← 最良
    30〜39秒  813,659回

**あと2秒縮めると一番いい帯に入る。**
削るなら、ネザーに入ってからピグリンを見つけるまでの移動（22〜26秒あたり）。

## 4. 題名

### 画面に焼く固定タイトル（適用済み）

    一番簡単な方法

7字。皮肉になっている（雷で強化して船で運んでネザーまで行くので、
まったく簡単ではない）。本家の「美しい」（25秒引っぱって何も起きない）と同じ使い方。

### YouTubeの題名（3案）

**推す案**

    ピグリンの頭を取るのに雷でクリーパーを強化して船でネザーまで運ぶドクタードーナツ

41字。252本で数えると**20字以上が最強**（中央値964,294回）。
煽らずに、やった事を順番にそのまま書く。手順の面倒くささが読むだけで伝わる。
本家の

    ドクタードーナツ、ドロッパーに降りるだけで特に深い意味はありません。（34字・5,058,004回）

と同じ形。

**予備**

    強化版爆弾マンでピグリンの頭を取るドクタードーナツ      （25字・自分で作ったあだ名を題名に）
    ピグリンの頭が一番簡単に手に入る方法を教えるドクタードーナツ（30字）
