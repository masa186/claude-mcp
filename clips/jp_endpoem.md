# 日本語版台本 ── エンドポエムが分からん男

素材： `Edited_20260901_033523.mp4` 162.9秒。使うのは 1:40〜2:10 の30秒。

## この素材が今までで一番いい理由

|  | 突出 | レンジ |
|---|---|---|
| **この素材（全体）** | **7.1%** | **7.4** |
| フグ事件（1,837万回） | 6.2% | 6.4 |
| エンドラ討伐の素材 | 2.1% | 5.6 |
| その前の125秒 | 3.7% | 5.7 |

**1,837万回のクリップより音に山がある。** これまで上げてもらった素材で唯一。

さらに 75〜95秒が -36〜-38dB のほぼ無音で、**溜めに使える谷**まである
（SMPクリップの「ストーカー」は中盤を -36dB まで落として溜めていた）。

## 中身 ── ここに本物のオチがある

エンダードラゴンを倒したあと、Minecraft のエンドポエム
（「I see the player you mean...」で始まる、壮大で哲学的なエンディング文）が
流れる。その横でドクタードーナツが**同じことを4回言う。**

    What is he talking about?  （こいつ何言ってんだ？）

**天丼（同じボケの繰り返し）。** マインクラフトclips の365万回の動画が
使っていたのと同じ仕掛け（あれは「何度も自分が鬼になる」天丼だった）。

### 裏取り

声の帯（300〜3400Hz）のエネルギーを地の値と比べて、
台詞がある所に本当に声があるかを確かめた。

    3.0秒   +7.4dB  声あり   ✓
    9.0秒   +6.6dB  声あり   ✓
    15.0秒  +9.0dB  声あり   ✓
    18.0秒  +5.4dB  わずか（笑い声なら妥当）
    24.0秒  +1.4dB  ★声なし  ← Gemini が置いた台詞だが実際には無い。落とす
    30.0秒  +8.0dB  声あり   ✓

**4回の繰り返しは全部本物。** 1行だけ作り話が混じっていたので削った。

## 構造の判定（5チャンネルの基準に当てはめる）

| 基準 | この素材 | 前のエンドラ台本 |
|---|---|---|
| 0〜5秒で約束 | **○** ポエムが流れ出す＝感動の結末が来ると分かる | × 結果から始まっていた |
| オチの型 | **B 予想を裏切る**（感動の結末 → 誰も理解していない） | E オチが無い |
| 途中の小さな山 | **○** 繰り返しが山そのもの（3回目・4回目で効く） | × |
| 最後の3秒 | **○ 追い打ちにできる**（ポエムは止まらない） | × 余韻だった |
| もう一度見たくなる | **○** ポエムの文を読み返したくなる | × |
| ネタ元の知識 | **○** エンドポエムを知っていると倍おもしろい | △ |

**6項目すべてを満たす。** 前の台本は5つ落としていた。

## 型 ── マインクラフトclips

    企画のエンジン  天丼（繰り返しの笑い）＝マインクラフトclips の得意技
    色           2色だけ。ドーナツ＝白／ポエム＝緑
                 マインクラフトclips は白1色＋タイトルの赤だけで回している。
                 話者が2つしかないこの素材に、SMPクリップの4色は要らない
    「w」        マインクラフトclips は「w」を多用してテンポを作る。ここでも使う
    帯           上に固定タイトル（全チャンネル共通）

## 音

    素材を -11.5 LUFS へ正規化（元は -20.9）
    3回目の「何言ってんの」に効果音を1つだけ置く（sound.swap）
    ポエムのBGMはそのまま。谷（無音）を消さない

**効果音は3回目にだけ置く。** 天丼は3回目が一番効くので、そこだけ強調する。
毎回鳴らすと繰り返しの効果が消える。
