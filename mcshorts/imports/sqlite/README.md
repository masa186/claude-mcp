# imports/sqlite/

Termux などで作った SQLite の分析データを置く場所。

## 段階2での扱い（目録だけ）

- `build_dataset.py` が**読み取り専用**（`mode=ro&immutable=1`）で開き、表・ビュー・列・型・行数の一覧を
  `reports/coverage.md` と `data/imports.json` に出す
- 開く前と後で SHA-256 と更新時刻を比べ、ファイルが変わっていないことを確かめる
- **中身は取り込まない。** 観測・書き起こし・分析結果のどこにも入らない
- `-wal` ファイルがあれば「WAL あり」と表示する（immutable で開くため、WAL に残る未反映の変更は目録に含まれない）
- DB ファイル（`*.db` `*.sqlite` `*.sqlite3`）は `.gitignore` で除外している。中身を確かめてからコミットするかを決める

## 取り込むとき（後の段階）

目録を見て、どの表のどの列が何にあたるかを `mapping.json` に書く。対応表が無い表は取り込まない（推測しない）。
書き方は実際の DB を見てから決める。段階2では `mapping.json` があっても取り込まず、「対応表あり・未取り込み」と表示するだけ。
