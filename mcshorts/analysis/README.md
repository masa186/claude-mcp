# mcshorts/analysis — 段階4（分析）

段階4a：規則に基づく数値・タイトル・テキスト分析。**Dream Clips と SMP Clips は別々に集計し、混ぜない。**

```bash
python3 mcshorts/analysis/run_4a.py             # out/ を作り直す（ネットワークは使わない）
python3 mcshorts/analysis/run_4a.py --out DIR   # 別の場所に作る
```

## 読むもの（すべて読み取り専用）

- `mcshorts/data/videos.jsonl`・`features.jsonl`・`transcripts/`
- `tools/tn_feat.py`（人名の一覧・文末の型などの関数を借りるだけ。ソースを読んで実行し、`tools/` にキャッシュを書かない）

## 設定（`config.json`）

| 項目 | 値 | 意味 |
|---|---|---|
| `views_basis` | 最新の API 観測 | 動画ごとに、取得日時の分かる API の観測のうち最も新しいものを使う。無い動画は別枠 |
| `min_age_days` | 30 | 投稿から30日未満は「伸びている途中」として比較から外す（別枠） |
| `max_duration_sec` | 180 | 180秒を超える動画は別枠 |
| `top_share` / `bottom_share` | 0.2 | 相対再生の上位20%・下位20%を比べる |
| `neighbors` | Dream 7・SMP 15 | 相対再生＝再生数 ÷ 投稿順で前後 N 本（自分を除く）の再生数の中央値 |
| `min_n` | 5 | 上位・下位のどちらかで値のある動画が5本未満なら「判断保留」 |
| `q_threshold` ほか | 0.1 など | 「差あり（傾向）」の判定（多重比較を補正した q 値と効果の大きさ） |

## 出力（`out/<channel>/`）

| ファイル | 中身 |
|---|---|
| `summary.md` | 対象と別枠、上位・下位の一覧、差が見られた特徴、判断保留、データの状態 |
| `videos.csv` | 動画ごとのグループ・順位・相対再生・再生数・経過日数など |
| `features.csv` | 動画ごとの特徴（値が無いものは空欄。0 で埋めない） |
| `compare.csv` | 特徴ごとの上位・下位の比較（中央値または割合、効果、p、q、判定） |
| `../inputs.json` | 入力ファイルの SHA-256 と設定 |

## 決まりごと

- 差は**相関**で、原因とは限らない
- 値が無い・確認されていないものは推測で埋めない。未確認のデータに基づく比較は「根拠の状態」が `UNVERIFIED`
- 上部タイトルは「確認済み＋未確認」と「確認済みのみ」の2通りで比べる
- SMP は全編のナレーション・字幕・実測が無いので、それらの分析はしていない（段階3の後で行う）
- `out/` は手で直さない。テストが、コミットされた `out/` と作り直した結果が同じであることを確かめる
