# Dream Clips 58本 分析

一覧は `data/videos.json`（番号・ID・題名・再生数・長さ・投稿日）。番号は受け取った一覧の番号（1＝新しい、58＝古い）。

## 何で確かめたか（記号）

分析の各行に、どの材料で確かめたかを付けている。**事実と考察を分けるため。**

| 記号 | 材料 | 確かさ |
|---|---|---|
| **[画面]** | 動画から切り出したコマを Claude が目で見て読んだもの。0〜3秒は0.25秒刻み、以降は字幕が変わるたび・カットのたび・最低2.5秒ごと | 見えたものだけ。動画は 240×426 の低解像度なので、小さい文字は読めないことがある |
| **[実測]** | ffmpeg と numpy で測った数字（カット、字幕の切替、音量、テロップの変化） | 機械的に測った値。カットは「隣のコマとの差が周りの3倍以上」の基準 |
| **[書き起こし]** | Whisper（large-v3-turbo）で書き起こした音声。日本語の回と英語の回の2回 | 合成音声の日本語はよく取れるが、聞き間違いはあり得る。画面の字幕と食い違うときは字幕を優先 |
| **[音タグ]** | AudioSet 分類器（AST）で1秒ごとに付けた音の種類（Music / Speech / 効果音 など） | 確率による自動判定。「BGMがある」は Music の値が続いているかで判断 |
| **[Gemini]** | Gemini に動画を見せて答えさせたもの | 無料枠の上限で **#01〜#14 の14本だけ**取れた。#02〜#14 は個別分析の後に届いたので、各ファイルの末尾に「Gemini による追記」として突き合わせた。参考扱い |
| **[考察]** | 上の材料からの Claude の解釈 | 事実ではない |

**Claude は音を直接聞けない。** 声の質・BGMの曲調・効果音の種類は、書き起こし・音タグ・Gemini を通した間接的な判断になる。
