# TikTok用の作り直し（59本の実測から）

## 0. 先に、自分の見立てを1つ訂正する

前に「0:02の離脱が最大の詰まりだ」と言った。**それは言い過ぎだった。**

Creative Center の上位59本の6秒視聴完了率を数え、こちらの第5話の値を
条件から逆算して比べた。

    参考59本の中央値          31.6%（23.5〜71.2%）
    第5話（逆算）             25〜40%、中心は30%前後

    逆算の式  p×S + (1-p)×2.5 = 6.0
      p  = 6秒以上見た人の割合、S = その人たちの平均視聴秒
      平均視聴6.0秒／尺43.12秒／フル視聴5.68%／「多くが0:02で停止」から
      p=20%だとS=20秒になり、フル視聴5.68%と矛盾する。p=30%前後が妥当

**継続率は「並」だった。外れ値ではない。** 0:02の離脱は直す価値があるが、
そこだけが原因ではない。

## 1. 本当に外れているのはここ

| | 第5話 | 参考59本 |
|---|---|---|
| 6秒視聴完了率 | 約30% | 中央値31.6% |
| いいね | **0** | — |
| シェア | **0** | — |
| 保存 | **0** | — |
| 再生 | 181 | 数百万 |

継続率が同じで再生数が桁違いなら、**差は反応の側**にある。
TikTokは継続率と反応の両方で押し出しを決める。片方が並でも、
もう片方が0なら伸びない。

## 2. フォロワー数は効いていなかった（これは朗報）

## 4. 尺が継続率を直接決めている

同じ「平均6.0秒見られた」でも、尺で継続率がこう変わる。

| 尺 | 継続率 |
|---|---|
| 15秒 | **40%** |
| 20秒 | **30%** |
| 43秒（第5話） | 14% |
| **84秒（第7話）** | **7%** |

**第7話をそのままTikTokに上げるのは勧めない。** 前に「同じファイルを
上げればいい」と書いたが、あれは撤回する。YouTubeで60〜90秒が最良
だったのはYouTubeの話で、TikTokの継続率は尺で割り算される。

**TikTokは20秒前後で別に作る。**

## 5. 「保存」される理由を作る

    保存されるもの  あとで使うもの（裏ワザ・手順・見分け方）
    保存されないもの 「へぇ」で終わるもの（1810年に缶詰ができた）

いまの型は歴史の話で、**保存する理由がひとつも無い。**
題材は変えずに、最後の1行を「明日使えること」にする。

## 訂正：膨張の計算を間違えていた

前に「60度で0.043mmの差」と書いた。**あれは誤り。**
ガラスの線膨張係数に 3.3e-6（耐熱ガラス＝パイレックス）を使っていたが、
**ジャム瓶はソーダ石灰ガラスで 9.0e-6。**

    鋼のフタ(12e-6) 対 ソーダ石灰ガラス(9.0e-6)
      → 比は1.3倍。60度上げても 径82mmで 0.015mm
    アルミのフタ(23e-6) なら 2.6倍で 0.069mm

Gemini はこの誤った値を受けて「鉄はガラスの4倍膨張する」と書いてきたが、
**これも誤り。**（そもそも4倍は元の3.6倍からさらにずれている）

**結論：「温めると膨張して開く」を主機構として語るのはやめる。**
差が0.015mmしかなく、フタの材質で結論が変わってしまう。
実際にはお湯で中の空気の圧力が上がる効果や、パッキンが軟らかくなる
効果も混ざっていて、どれが主かをこちらで確かめられない。

## 確かめられる物理だけで組む

真空がフタを押さえる力の計算は、材質にも機構の議論にも依存しない。

    力 ＝ 大気圧 × 真空度 × フタの面積
      径70mm・0.3気圧 → 11.9 kgf
      径82mm・0.3気圧 → 16.4 kgf

**この1本だけで動画が成立する。**
そして直し方が機構から素直に出る ── 力で回すのではなく、**真空を抜く**。

## 実写のどこを使うか（実測）

0.1秒ごとの画の変化量を測った。

    0.0〜7.0秒   0.33〜0.75   ほぼ動いていない
    7.5〜9.0秒   1.00〜1.46   回し始め
    **10.0〜10.5秒  3.65／3.18   ここが最大。フタが外れる瞬間**
    11.0〜13.0秒  1.1〜1.6     外した後
    14.0〜16.0秒  0.38〜0.71   静止

Gemini は「0:07〜0:09がフタが回り始める瞬間」と答えたが、**実測とずれている。**
一番動いているのは **10.1秒**。冒頭に置くならここを使う。
