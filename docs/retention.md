# 飽きさせない設計 — 参考動画の実測と、それに合わせた作り直し

参考にもらった2本を解析して、いまの第1話との差を数字で出した。
**結論：企画も台本も悪くない。カット速度が5倍遅いのが原因。**

---

## 実測

| | 尺 | カット数 | 平均カット長 | ほぼ静止の割合 |
| --- | --- | --- | --- | --- |
| 参考A（実写・メントスコーラ） | 45.2秒 | 34 | **1.33秒** | 55% |
| 参考B（解説・限界までズーム） | 49.7秒 | 30 | **1.66秒** | 30% |
| 第1話（作り直す前） | 46秒 | 6 | **7.70秒** | ほぼ全部 |
| **第1話（作り直した後）** | 47.5秒 | **29** | **1.64秒** | 0% |

参考Bのほうが企画として近い。**1.6秒に1回、画面が変わる。**しかも変わっていない時間も
ズームやパンで常に動いている（静止30%）。ここが「飽きない」の正体。

## 参考Bから取ったもの

| 参考の要素 | 取り入れ方 |
| --- | --- |
| **テロップが画面の主役。**大きく、太い黒フチ、キーワードだけ色 | テロップを84px・黒フチ7pxで常時表示。`{ }` で囲んだ語だけ黄色 |
| 素材が毎カット変わる | ショット種を4つに増やした（下記） |
| 常にズーム／パンしている | **全ショットに自動でズーム。**方向は in→out→left→in→right→out で自動巡回。静止するショットを作れない仕様にした |
| 左上にチャンネルのアイコンが固定 | キャラの顔を丸く切り抜いて常時表示。ブランド認知 |
| 数字・キーワードを赤や黄で強調 | 黄（`MUSTARD`）と赤（`CRIMSON`）の2色を使い分け |
| 章の区切りに黒背景＋白文字 | `title` ショットを追加。参考Aの「9日後」と同じ役割 |
| 最後に感情のカット | `face` ショット（顔アップ）で締める |

## キャラ画像を増やさずカットを5倍にする方法

**画像は5枚のままです。**ショットの「種類」を増やしただけ。

| ショット種 | 中身 | 追加素材 |
| --- | --- | --- |
| `wide` | 黒板＋キャラの通常構図 | なし |
| `face` | **同じ画像の顔だけをクロップして全画面。**まったく別の絵に見える | **ゼロ** |
| `board` | 黒板だけに寄る。図を大きく見せられる | **ゼロ** |
| `title` | 黒背景＋白文字。章の区切り | **ゼロ** |

内訳は wide 11／board 11／face 5／title 3 の29ショット。
**素材追加ゼロで、カット長を7.7秒から1.64秒に落とした。**

## BGMの設計

単一BGMを流しっぱなしにしない。**テンションを3段に分けて、1箇所だけ無音を作る。**

| 区間 | 秒 | BGM | 意図 |
| --- | --- | --- | --- |
| フック | 0〜3.4 | **無音、または一発だけSE** | 音がないと逆に注意が向く。ここで指が止まる |
| 匂わせ〜仕組み | 3.4〜28 | 軽快・音量18% | 情報を流す区間。邪魔をしない |
| 具体例 | 28〜35.8 | 音量22%に上げる | 「じゃあお皿は？」でテンションを一段上げる |
| **オチの直前** | 35.8〜37.1 | **完全に無音（1.3秒）** | `title`「つまり」のところ。**ここが一番効く。**無音は最強の注意喚起 |
| オチ | 37.1〜42.5 | 盛り上がる曲に切り替え・音量25% | 決め台詞を音で持ち上げる |
| 予告 | 42.5〜47.5 | 音量を落として余韻 | 次回への引き |

**曲は2曲使う。**「本編用」と「オチ用」。1曲を音量だけで上下させても、盛り上がりは作れません。

## テンポの原則（30本ぜんぶに効く）

1. **1ショットは1.0〜2.2秒。** 2.2秒を超えたら、そのショットは割る
2. **同じショット種を3回続けない。** wide→wide→wide は飽きる。face か board を挟む
3. **`title` を3枚入れる。** 冒頭の煽り／中盤の「気づき」／オチの直前。**オチ直前の1枚が最重要**
4. **黒板の内容を累積させない。** 1文言ったら次のショットで入れ替える。溜めると読まれない
5. **テロップは常に出す。** 音を切って見る人が7割。テロップだけで意味が通ること
6. **キーワードは1ショットに1語だけ色を変える。** 2語以上だとどちらも目立たない

## まだ足せるもの（次の改良候補）

- **赤い矢印と※注釈**（参考Bの「※光がずれてしまう」）。図の説明力が上がる
- **集中線・放射背景**（参考Aの黄色い背景）。`title` ショットの背景に使う
- **キャラの左右反転**。同じ画像をさらに倍に使える
- **「!?」の特大リアクション文字**。オチの直前に0.3秒だけ
- **口パク**。決め台詞の1文だけ、口の開閉2枚を0.15秒交互
