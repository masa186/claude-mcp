### ここで前の結論が1つ崩れる

化け学のふしぎ250本では「◯年間」などの**数字が1.78倍**だった。
このチャンネルでは**数字は0.89倍**で、逆に効いていない。

**数字の効き方はチャンネルによって逆になる。**
第7話の「48年間、誰も開けられなかった缶詰」は前者の型に賭けたもので、
このチャンネルの型では不利側に入る。どちらが正しいという話ではなく、
**題材とチャンネルによって別**というのが正しい読み方。

一貫して強いのは **「なぜ」と「理由」**、つまり
**分からないことの説明を約束する語**のほう。

# 第7話の結果（2026-08-25公開・14時間）

| | 第6話 | 第7話 |
|---|---|---|
| 尺 | 79.2秒 | 84.2秒 |
| 再生 | 1,182回（6時間） | 1,211回（14時間） |
| 平均視聴 | 0:45 | 0:48 |
| 平均視聴/尺 | 57% | **57%** |
| 登録者 | +1 | **0** |

**第7話でやった直しは、数字を動かさなかった。**
無音23%→9%、画と台詞の食い違い、図の作り直し、テロップの折り返し。
どれも品質としては直っているが、**再生数も維持率も第6話と同じ**だった。

    エンゲージビュー 609 / 1,211 = 50.3%
    視聴を継続 52.7% ／ スワイプして消去 47.3%
    ショートフィード 97.6%  未登録 99.2%  携帯 87.8%
    終了画面クリック率 0.0%  ハイプ 0

再生の伸びは4時間で頭打ちになり、そこから14時間でほぼ横ばい。
第6話も同じ形だった。**毎回1,100〜1,200で天井に当たっている。**
これは「最初の試し出しの枠」を使い切って、次の枠に進めていない形。

## そこから読めること

継続率57%は悪くない。**足りないのは反応と本数のほう。**
陰キャの憧れの いいね率1.03% に対して、こちらは いいね数が
表示される水準にすら届いていない。
