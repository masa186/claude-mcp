# 30日計画 ── 100万回と1000人

**気持ちではなく数字で組む。** 使うのは全部このセッションで実測した値。

---

# 1. 先に：この2つは今の効率だと両立しない

## 登録効率の実測（1万回あたり何人登録するか）

    こちらの1本目        2.79人/万回   （14,336回で +4人）
    SMPクリップ           2.84人/万回
    ドリームクリップ       6.39人/万回   ← 測った10チャンネルで最高

## 1000人に必要な再生数

    こちらの今の効率      3,584,000回
    ドリームクリップ水準   1,565,000回   ← 最高効率でもこれ

## 逆に、100万回で何人登録するか

    こちらの今の効率        279人
    ドリームクリップ水準     639人

**100万回では1000人に届かない。** 最高効率でも639人。
1000人には**150万〜360万回**が要る。

→ **30日で現実的なのは「100万回 ＋ 300〜600人」。**
   1000人は2〜3ヶ月目の数字。

**これは諦めろという意味ではない。** 100万回は届く。
1000人だけ、30日という枠が合っていない。

## ついでに：収益化のしきい値

ショートで収益化するには **登録1000人 ＋ 90日で1000万回**。
30日で100万回なら90日換算で300万回＝**しきい値の30%**。

**30日は「型を固めて、伸びる形を確定させる」期間**であって、
収益化に届く期間ではない。ここを取り違えると途中で折れる。

# 2. 100万回はどう出すか

    30本（1日1.0本）× 中央値 33,333回
    45本（1日1.5本）× 中央値 22,222回
    **60本（1日2.0本）× 中央値 16,667回**   ← ここが現実的
    90本（1日3.0本）× 中央値 11,111回

**こちらの1本目は 14,336回。**
つまり**1日2本、1本目と同じくらいの出来を60本並べれば届く。**

新しい何かを発明する必要はない。**本数だけ。**

SMPクリップの実測も **1日1.7本**（同じ日に複数出すのが41%）。
2本/日は本家と同じペース。

# 3. 何を直せば1本あたりが上がるか（全部実測済み）

| 直すこと | 根拠 | 効き |
|---|---|---|
| **1080×1920 / 30fps で書き出す** | 2本目がショートフィード0%だった。4K60は処理が長引き、伸び始めの数時間を逃す | **最大** |
| 尺を20〜29秒に寄せる | 252本で中央値914,983回。40〜49秒は523,417回で唯一の谷 | 大 |
| 題名を20字以上に | 20字以上が964,294回、1〜4字は644,663回 | 大 |
| 題名にw・数字・#を入れない | wを入れた12本は388,348回＝中央値の46% | 中 |
| 15〜19時に投稿 | SMPクリップは48%をこの時間に固めている | 中 |
| 音を圧縮しない | 突出41.1%→7.0%まで潰れた回があった。編集ソフトのノーマライズを切る | 中 |
| 透かしの出る編集ソフトを使わない | clideo.comが2回入った | 中 |

**この7つは全部「やるだけ」で、腕は要らない。**

# 4. 60本の内訳 ── 2本柱で回す

| 型 | 本数 | 素材 | 根拠 |
|---|---|---|---|
| **切り抜き型** | 40本 | DrDonutのショート（33本ある）＋ 他の海外勢 | 鉄ゴーレム14.7秒＝元1472万回 |
| **見る型** | 20本 | ドクタードーナツが他人の動画を見ている素材 | 14秒で337万回。〜19秒帯の1位 |

**見る型を2割入れるのが要。**（`docs/smp_reaction.md`）
素材が「映像のオチ＋見た人の反応」で二重になっているので、
字幕が薄くても持つ。実際 Plot twist は9枚で足りた。

# 5. 週ごとの設計と、続けるかの判断基準

## 第1週（1〜7日）── 型を固める。14本

    目標  1日2本／累計14本
    やること
      ・書き出しを 1080×1920/30fps に固定する
      ・尺を20〜29秒に寄せる
      ・切り抜き10本、見る型4本
    **判断基準（7日目に見る）**
      ショートフィードの比率が全本で 80%以上あるか
      → 下回っていたら書き出しか尺の問題。ここで直す

## 第2週（8〜14日）── 当たりの形を探す。14本（累計28本）

    やること
      ・第1週で上位3本と下位3本を並べて、何が違うか測る
      ・当たった型に寄せる
    **判断基準**
      1本あたりの中央値が 10,000回を超えているか
      → 超えていれば60本で60万回。超えていなければ素材選びを変える

## 第3週（15〜21日）── 寄せる。16本（累計44本）

    やること
      ・当たった型だけを回す。実験をやめる
      ・1日2本を崩さない
    **判断基準**
      累計40万回に乗っているか

## 第4週（22〜30日）── 積む。16本（累計60本）

    やること
      ・同じ日に2本出す日を増やす（本家は41%が複数投稿）
    **判断基準**
      累計100万回

# 6. 分担

## そちらがやること

    ① 素材を渡す              ← ここが唯一の詰まり
    ② 上げる（題名・説明欄・時間はこちらが出す）
    ③ 週1回、アナリティクスの画面を見せる

## こちらがやること

    ・素材を測る（尺・動き・カット・音・声の位置）
    ・字幕を書く（52本の型で）
    ・焼く（1080×1920/30fps・音は圧縮しない）
    ・題名と説明欄を出す
    ・週次で数字を突き合わせて、次の週の設計を直す

**焼くのは1本1分。詰まるのは素材の供給だけ。**
1日2本なら、素材を1日2本ぶん渡してもらえれば回る。
まとめて10本渡してもらっても構わない。

# 7. 素材をどこから取るか

    DrDonut 本体          短編33本（うち鉄ゴーレム1472万回、43M・33M・32Mが上位）
    DrDonut Reacts        「見る型」の素材はここ
    Daquavis / Farex など DonutSMP周辺のクリエイター
    SMPクリップが使った元動画  同じ素材で先例があるので外れにくい

**DrDonutの短編は配信の切り抜きではなく撮り下ろし**（`docs/golem_origin.md`）。
最初からオチが設計された完成品なので、字幕だけで勝負できる。

# 8. 落ちる場所を先に潰しておく

    ・4K60で書き出す          → ショートフィードに載らない。2本目がこれ
    ・音をノーマライズする      → 突出が41%→7%まで潰れる。編集ソフトの自動調整を切る
    ・透かしの出るソフトを使う  → clideo.comが2回入った
    ・尺を40〜49秒にする       → 252本で唯一の谷（中央値の62%）
    ・題名にw・数字・#を入れる  → wは中央値の46%
    ・毎日出すのをやめる        → 本数が唯一の確実な変数

**60本出せば100万回は届く。届かないとしたら、上の6つのどれかを踏んでいる。**

# 9. 30日後に何が残るか

    再生数     100万回（届く）
    登録者     300〜600人（1000人は届かない）
    本数       60本
    確定するもの **どの型が当たるかの答え**

**30日の本当の成果物は「型の確定」。**
それが決まれば2〜3ヶ月目に1000人と、90日1000万回が見えてくる。

1000人を30日に押し込もうとすると、
本数を落として1本に賭けることになり、**確率が下がる。**
本数で殴るほうが、同じ努力で先に着く。
