# 実績のある編集者からの添削と、その検証

Discord の添削チャンネルで第12話を見てもらった。相手の実績は
1日で登録者+8,453／推定収益83万円／28日で1,948万回。数字は本物。

指摘をそのまま受け取らず、全部こちらで測り直した。
**測って当たっていたものと、こちらの見立てが外れていたものを分けて書く。**

## 1. 数字で当たっていた指摘

### 効果音がうるさい

`pipeline/measaudio.py` で、200msごとの音量が中央値より6dB以上大きい
区間の割合（＝突き出た音の量）を測った。

| | ラウドネス | レンジ | 突出 |
|---|---|---|---|
| **第12話（直す前）** | **-13.9 LUFS** | 6.0 | **13.9%** |
| 参考1 化け学 | -9.8 | 9.0 | 0.0% |
| 参考3 無限の机 | -12.3 | 3.1 | 4.0% |
| 参考4 無限の机 | -11.9 | 4.2 | 4.5% |
| 参考5 無限の机 | -12.3 | 6.1 | 10.9% |
| 参考6 無限の机 | -12.0 | 4.5 | 6.1% |
| 中央値 | **-12.0** | 4.5 | **4.5%** |

参考の3倍。しかも全体は参考より**小さい**。
つまり「効果音がうるさい」と「ナレーションが小さい」が同時に起きていた。
相手が別の投稿で挙げていた13選に、その2つが両方入っている。

直し方：効果音を0.42倍に落とし、最後に `loudnorm` で -12LUFS へ揃える。

### キャラがドアップで右左に動く

原因は `render.apply_zoom`。顔のカットは `PAN=0.84`、つまり
**画面の84%を横切って振っていた。** 実測すると1.6秒のカットの中で
カワウソの面積が 18%→41%（2.3倍）、別のカットでは 6.7%→28.6%（4.3倍）。
横の重心も画面幅の7%ぶん振れていた。

直し方：寄りと振りを話ごとに下げられるようにして、第12話は
寄り1.34→1.10、振り0.84→0.14、揺らぎ0.06→0。

### 図表がズームで読みにくい

`fig.py` に `LIVE` を足して、第12話は 0（止める）。
理由は次の節に書く。

### ナレーションが遅い

4.47文字/秒。参考6本の中央値は6.59。これは指摘される前から分かっていた。
原因は台本ではなく、枠が残っている音声モデル（3.1）が遅いこと。

### 結論を言ったらすぐ終われ

締めの2ショット（「今日、どれかやってへん？」「1日52人やからな」）を
落とした。**ここはこちらが理屈で守っていた所だった。**
ショートはループするのでループぶんも再生時間に数えられる、
だから頭へ返す理由を置く、と考えていた。

落としてみたら:

    40.3秒 / 較正後の見込み 70%
    → 32.4秒 / 較正後の見込み 74%

**理屈で守っていた6秒が、狙っていた数字そのものを4ポイント下げていた。**
ループの理屈自体は間違っていないと思うが、3ショット8秒は明らかに払い過ぎ。

## 2. こちらの見立てが外れていた（一番大事）

「参考は動きが多い、うちは足りない」と書いて、`fig.py` に
揺れ・脈打ち・行き過ぎを足した。参考6本を同じ物差しで測り直したら、
**その前提が肝心なところで間違っていた。**

| | 動きの中央値 | 上位5% | 比 |
|---|---|---|---|
| 第12話 | 1.58 | 6.80 | 4.3倍 |
| 参考1 化け学 | **1.55** | **26.47** | 17.1倍 |
| 参考3 無限の机 | 1.91 | 15.81 | 8.3倍 |
| 参考6 無限の机 | 1.70 | 12.80 | 7.5倍 |

**参考の「普段の動き」は、こちらと同じだった。** 1.55 対 1.58。
向こうは常時ウネウネ動いていない。違うのは変化の**大きさ**で、
上位5%が 26.5 対 6.8 と4倍開いている。

向こうの動きは「新しい画が来る」ことで出ている。
こちらは「同じ絵を揺らす」で数字を埋めようとした。
中央値はわずかに上がったが、実際に差がある所は埋まらず、
読みにくさだけが残った。**編集者が見たのはその結果。**

これが、相手の最後の一言につながる。

    雑学系やりたいならこういうフォーマットに落とし込んだ方が良さそう
    （陰キャの憧れ「外国人が驚いた日本の当たり前」）

## 3. AI に言わせた分（割り引いて読むこと）

Gemini にも動画を見せたが、**先に指摘文を読ませているので、
同意したこと自体は証拠にならない。** 7点中6点で「当たり」と言ったが、
それは引きずられただけの可能性がある。上の数字のほうを信じること。

Gemini が自分から足した中で1つだけ拾う価値があった:

> 年間1万9千人が死ぬという深刻な話なのに、コミカルなカワウソが
> 蝶ネクタイで動くので、切実さが薄れている。

題材とキャラの相性は、12話ぶん一度も考えていなかった。
「危ない」系は同じ型888本で3.65倍と一番強い語だが、
その強さとマスコットが噛み合うかは別の話。
