# 336万再生の長尺を実測して、画面の作りを変えた

## まず実測

送ってもらった2本（4分41秒／7分00秒）を1秒ごとに切り出して、
前の秒とどれだけ画面が変わったかを数えた。

| | 参考A | 参考B | 前のカワウソ第2話 |
| --- | --- | --- | --- |
| ほぼ同じ（変化 8%未満） | **92%** | **96%** | ほぼ0% |
| 一部だけ変わる（8〜35%） | 5% | 3% | ほぼ0% |
| 全面入れ替え（35%超） | 3% | **0%** | ほぼ100% |

つまりあの2本は、**ほとんど動いていない**。

「動きが多いから見やすい」ではなかった。逆だった。
**レイアウトが動かないまま、中身だけが1つずつ足されていく**。
だから視聴者は毎秒「今どこを見るんだっけ」を探し直さなくて済む。

こちらの前の版は、カットのたびに画面を丸ごと差し替えていた。
カットとしては動いているが、視聴者から見ると
**毎回ちがうスライドが出てくる**のと同じだった。ここが一番の差。

## 画面の役割分担（原寸で採寸した）

参考Bの1コマ（852×480）を測った結果:

```
┌────────────────────────────────┐  0%
│ 空間の縮み                        │  章タイトル（左上・出しっぱなし）
│                                │  8%
│        メインの図解                │
│        （ここだけ見ればいい）        │
│                                │  72%
│ 🧑                          🧑  │  キャラは左右の隅。下端で切れている
│      字幕（2行・小さい）           │  78〜96%
└────────────────────────────────┘
```

- **章タイトル**は左上に出しっぱなし。話が進んでも「いまどの話か」が消えない
- **キャラは主役ではない**。隅に固定で、動かない。案内役に徹している
- **字幕は見出しではない**。声の書き起こしであって、読ませる文字ではない
- 中央の図は、要素が**1つずつ増える**。式が出る → 行が足される → 数字が赤で消される

## 何が問題だったか

前の版は、1画面の中に主役が4つあった。

```
カワウソ（大きい）／ 黒板の大文字 ／ 下のテロップ ／ 図
```

黒板に「空気が下へ曲がる」と大きく出しながら、
下のテロップでも同じことを言っていた。**中央を読んで、下も読む**になる。
どちらを見ればいいのか決まっていなかった。

## 変えたこと

`stage` という画面の型を足した。

```
┌────────────────────────────────┐
│ なぜ浮くのか                      │  章タイトル（左上・出しっぱなし）
│                                │
│         図（主役）                │  10〜56%
│                                │
│                                │
│      翼は少し上を向いてる          │  ← 前の結論（薄い）
│      空気が下へ曲がる             │  ← 前の結論（薄い）
│      だから翼は上へ               │  ← いまの結論（濃い）。位置は毎回同じ
│      字幕（小さい）        🦦     │  カワウソは右下・固定
└────────────────────────────────┘
```

決めたルール:

1. **主役は図**。カワウソは案内役として右下に小さく固定。顔アップは
   フックとオチとリアクションだけに絞った
2. **結論は消さずに積む**。1つの舞台の上で話が進む。新しい行はいつも同じ高さに
   出るので、視線が動かない
3. **字幕は小さく下に**。見出しではなく声の補助。大文字と同じことを言わない
4. **章タイトルは左上に出しっぱなし**
5. **文字とカワウソは寄りの外**で描く。寄せるのは背景と図だけ。
   レイアウトが1pxも動かない（前の版は寄りに巻き込まれて字幕とぶつかっていた）

## 図に説明させる

参考動画の一番の強みは「絵を見るだけで意味が分かる」ことだった。
矢印を1本置いて「下に曲がる」と書くのは、絵ではなく文字で説明している。

そこで図を作り直した。

| 図 | 何を見せるか |
| --- | --- |
| `wingrace/` | 上下の空気が同時に出発して、上だけ先に着く。学校の説明の反証を目で見せる |
| `aoa/` | 翼が水平から起き上がる。「少し上を向いている」を比較線つきで |
| `hand/` | 車の窓から出した手。**翼の図とわざと同じ見た目**にした |
| `airflow/` | 空気が翼に沿って下へ抜ける。曲がっていないときの高さを点線で残してある |
| `airlift/` | 同じ流れ＋上向きの矢印 |

`hand/` を翼の図とそっくりに描いたのが効く。
「あれと同じ」と言葉で言うより、**同じ絵に見えること自体が説明**になる。

## 結果

第2話を測り直した:

| | 参考動画 | 前の版 | いま |
| --- | --- | --- | --- |
| ほぼ同じ | 92〜96% | ほぼ0% | **35%** |
| 一部だけ変わる | 3〜5% | ほぼ0% | **26%** |
| 全面入れ替え | 0〜3% | ほぼ100% | **40%** |

参考動画と同じ数字にはしていない。あちらは4〜7分の長尺で、
視聴者が腰を据えて見ている。こちらは40秒で、最初の1秒で止められる。
**全面入れ替え40%は残した**（フック・実写・オチ・予告）。
残りの60%を「1つの舞台の上で進む」に変えた。ここが今回の変更点。

## まだ残していること

- 第1話（電子レンジ）は前の画面の作りのまま。第2話で形が固まったら移す
- 実写（飛行機の映像）はスクリーンを降ろす演出のまま。参考動画も
  中央の素材を写真に差し替えていたので、これは今のままでいい
