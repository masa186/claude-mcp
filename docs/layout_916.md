# 9:16の素材にSMPクリップの型を当てるときの、寸法の問題

3本とも素材が **480×854（すでに9:16）** で、顔カメラが焼き込まれている。
SMPクリップの帯割りは**そのままでは物理的に入らない。**

## 何が起きるか

SMPクリップの本編帯は 1080×1210px（縦横比 **0.89**）。
16:9の素材（1.78）を入れる前提で、高さを埋めて横を切る設計になっている。

こちらの素材は 480×854（**0.56**）。

    横1080に合わせる → 高さ 1921px（帯1210pxに 711px はみ出す＝37%を捨てる）
    高さ1210に合わせる → 横 680px（左右に 400px の黒が出る）

**37%も捨てると、顔カメラかゲーム画面のどちらかが丸ごと消える。**
左右に黒帯を出すと、ショートで画面が細くなって不利。
どちらも取れない。

## 実測して決めたこと

3本の上端を切り出して、顔の上にどれだけ余白があるか測った。

    ドリームクラッチ   頭の上端 ＝ 画面の 11.6%
    The Ending        頭の上端 ＝ 画面の  9.2%   ← いちばん余裕がない

**上を切っていいのは 9% まで。** それ以上切ると頭が欠ける。
9%＝1920pxのうち173px。SMPクリップのタイトル帯は403pxなので、**足りない。**

## 結論：タイトル帯は作らず、素材の余白に文字を置く

    素材を 1080×1921 に拡大し、上を1px、下を0px 切って 1080×1920 に収める
      （＝ほぼ全画面。切らない）
    黄色い極太タイトルを、画面の上 0〜9%（0〜173px）に直接重ねる

3本とも、顔の上は**壁とテレビと椅子だけ**の平らな暗い面で、
黄色＋太い黒フチの文字を置いても十分読める。**黒帯を敷く必要がない。**

これはSMPクリップの型を崩したのではなく、
**「タイトルを全編出しっぱなしにする」という型の目的をそのまま満たす、
9:16素材でのやり方**にあたる。
実際、本家（Dr Donut／カイ×スピード）の9:16ショートも黒帯を作らず、
顔カメラの上や下端に直接文字を焼いている。

## 下の黒帯について

SMPクリップは下 84〜100%（307px）を真っ黒にして何も置いていない。
こちらは素材がそこまで詰まっているので、**下の黒帯も作らない。**
かわりに**字幕をホットバーの少し上**（y≈1400〜1500）に置く。
3本ともホットバーが画面の最下部にあり、体力のハートが物語に効いている
（ゴーレム＝減っていく／クラッチ＝満タンのまま／The Ending＝黒くなる）ので、
**ホットバーは絶対に隠さない。**
