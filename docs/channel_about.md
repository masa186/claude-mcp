## 先に結論：説明欄では登録者は増えない

**説明欄の字数と「1本あたり登録」の相関 r ＝ +0.175。ほぼ無関係。**

決定的なのは上位3本。

    1位 ぷんきち          700字の長文       1,208人/本
    2位 海外マイクラ切り抜き  24字の一行        963人/本
    3位 しうん            **説明欄が空**     847人/本（登録40万）

**長文の1位と、空欄の3位が並んでいる。** 説明欄が効いているなら、こうはならない。

理由ははっきりしていて、**ショートの視聴者は説明欄を見ない。**
ショートフィードから登録する人は、チャンネルの「概要」タブを開かない。
こちらの1本目も**視聴の97.6%がショートフィード**だった。

→ **「極限まで登録者を増やす説明欄」は存在しない。**
   登録者を増やすのは動画で、説明欄はその邪魔をしないことが仕事。

## それでも説明欄には3つの仕事がある

### ① YouTube検索に載る（最初の100字だけ）

説明欄は検索の対象になり、**先頭の約100字**が検索結果でチャンネル名の下に出る。
だから**1行目に「何のチャンネルか」を検索されうる言葉で書く。**

### ② 収益化審査の「再利用されたコンテンツ」対策 ← これが本命

翻訳・切り抜きチャンネルが収益化を落とされる理由はほぼこれ1つ。
**元の素材に自分の価値を足していることを、審査する人間が読む場所に書いておく。**

実際、上位のチャンネルはここを意識して書いている。

    海外面白ショート（登録12万）
      「当チャンネルは海外でバズった動画を翻訳・日本語テロップ付け・
        ショート用の再編集を行うチャンネルであり、著作権侵害の目的や意図はありません」

    ゲーマー翻訳（登録16.2万）
      「全て日本語字幕を付けているので英語学習にご利用いただけます！」← 付加価値の主張

**「翻訳した」「テロップを付けた」「短く再編集した」を明記する。**

### ③ 権利の立場を宣言する

    MCトラップクリップ  「非公式切り抜きですが許可は頂いてます」
    SMPクリップ        「私になりすますことさえなければ、コンテンツの内容や
                        チャンネルのコンセプト、編集スタイルなど、
                        すべて許可なく自由に真似していただいて構いません」

**※「許可は頂いてます」は、本当に貰っていない限り書かないこと。**
嘘の権利表示は、それ自体が問題になる。

# 新チャンネルの説明欄（そのまま貼れる形）

```
海外マイクラの面白い場面を、日本語字幕を付けてショートにしています。

DrDonut / DonutSMP を中心に、英語の実況や配信から見どころだけを切り出し、
日本語に翻訳して字幕を付け、短く再編集しています。
英語が分からなくても、そのまま笑えるようにするのが目標です。

元の動画は各ショートの説明欄にリンクを置いています。
権利者の方でご要望があれば、すぐに対応しますのでご連絡ください。
```

**この形にした理由**

    1行目   「海外マイクラ」「日本語字幕」「ショート」＝検索される言葉を先頭に。
            検索結果に出るのは先頭100字だけなので、ここに全部入れる
    2段落目  **翻訳・字幕・再編集** の3つを明記。収益化審査で
            「再利用されたコンテンツ」と判定されないための本命
    3段落目  出典の導線と、権利者への窓口。
            「許可は頂いてます」とは書いていない（貰っていないなら嘘になる）

**約150字。** 上位のゲーマー翻訳（160字・844人/本）と同じ量。

## 短く行くなら（こちらでも数字は変わらない）

```
海外マイクラの面白い場面を、日本語字幕を付けてショートにしています。
翻訳・字幕・再編集はすべてこちらで行っています。
元動画のリンクは各ショートの説明欄にあります。
```

## Discordを作るなら1行目の上に

SMPクリップは説明欄の**一番上**にDiscordを置いている。
ただしこれは登録10万を超えてからの話で、**最初は要らない。**
人がいないDiscordのリンクは、逆に「過疎チャンネル」の印になる。

# 説明欄より先に効くもの

19チャンネルの数字を見た上で、登録者に本当に効く順。

    1. 動画の中身（1本あたり登録の差はほぼ全部これ）
    2. チャンネル名 ── 検索とショートフィードの両方に出る唯一の文字
    3. アイコン ── ショートで名前の横に出る
    4. 説明欄 ── 相関 r=+0.175

**チャンネル名のほうが説明欄より遥かに重い。**
上位はどれも一目で内容が分かる名前になっている。

    海外マイクラ切り抜き／ゲーマー翻訳【海外の反応】／
    タカツメ【日常組切り抜きアニメーション】／True【マイクラ】

**【】でジャンルを補うのが定番。** こちらも
「〇〇【マイクラ切り抜き】」の形にすると、名前だけで内容が伝わる。
