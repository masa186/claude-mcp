## 4. 書き方の型が6つある

### ① 括弧 ( ) ＝ツッコミ・心の声・悪態

**これが「面白い字幕」の主力。** アスタリスク *〜* とは役割が違う。

    (どけニート村人)      ← 邪魔な村人への悪態
    (抑えきれない笑い)    ← 声を言葉にしない書き方
    (Wemmbu付き)          ← 最後にぼそっと足す一言

    *アスタリスク*  客観的な状況。「これは実際の声ではない」という印
    (括弧)          編集者のツッコミ。感情が入る

こちらは**アスタリスクしか使っていなかった。**
だから全部が説明文になり、誰の感情も乗らなかった。

### ② たとえる（関係ない状況に喩える）

    *ポケカで数十万レベル引いて指紋すらつけたくない時の反応*

「大事にしている」を「大事にしている」と書かない。
**視聴者が知っている別の場面に置き換える。** ここが一番効いている。

### ③ 名前を付ける

    歩く鉄（鉄ゴーレム）／ニート村人／理論値村人／氷が反社／冷笑系Dream

物や人に**あだ名を付ける。あだ名そのものが笑い。**
「鉄ゴーレム」と書かずに「歩く鉄」と書く。

### ④ 列挙してエスカレートさせる

    超規模監獄 → マグマの壁 → 無限城 → ウォール・マリア
    → 存在しない世界への扉 → 軌道爆撃砲 → 護衛

赤で短く、どんどん大袈裟にしていく。**元ネタの固有名詞**（無限城＝鬼滅、
ウォール・マリア＝進撃）を混ぜる。最後に「護衛」と急に地味なものを置いて落とす。

### ⑤ 敬体で書くとおかしい

    それ相応のセキュリティが必要です
    配信視聴者に見せつけます

くだらない事を**丁寧語で真面目に**書く。この落差が笑いになっている。
「見せる」ではなく「見せつけます」。動詞を1段強くする。

### ⑥ 喋っている素材では、笑いを足さない

クッションの動画は最初から最後まで**ただの翻訳**で、ジョークがゼロ。
本人がずっと喋っているので、字幕が足すと潰し合う。

    喋りが多い素材  → 短く割ってそのまま訳す（クッション）
    喋りが少ない素材 → 括弧とたとえで編集者が喋る（理論値村人・歩く鉄）

**こちらの鉄ゴーレムはセリフが1本しかない＝後者。**
編集者が喋らないと、画面に何も無い時間ができる。

## ここで3つ間違いが分かった

### ① 赤の *〜* は「状況説明」ではなかった

前に「赤＋アスタリスク＝状況説明・心の声」と書いた。**違った。**

    *心を無にして見てください*    ← **視聴者に話しかけている**
    *無音に耐えてくれドパさん*    ← **配信者に話しかけている**
    *こ、こない*                  ← 緊張を代弁している
    *氷1億個設置完了*             ← 事実を1枚で出す

**赤は「編集者の声」。** 画面を説明する声ではなく、
画面の外から視聴者と配信者に喋りかける声だった。

こちらが書いていた「*板を並べる*」「*穴を掘って隠れます*」は
**画面を見れば分かる事を書いているだけ**で、
編集者が喋っていないから誰の声にも聞こえなかった。

### ② 導入は「一つの文」を4枚に割っている

    ドクタードーナツが / ゴーレムの倒し方を / 配信視聴者に / 見せつけます
    ドパガキの / 心が浄化される / 絶景が / こちら

**名札を並べているのではない。文を割っている。**
「〜がこちら」「〜します」で終わる、テレビのナレーションの形。

こちらの「第一の作戦：土の柱」「第二の作戦：石の斧」は
**名札の羅列**で、文になっていなかった。

### ③ 「3〜6文字で次々切り替える」は導入だけだった

前に「1カット3〜6文字で切り替わるのがテンポの正体」と書いたが、
**それは最初の3〜4秒だけ。**

氷が反社は `*こ、こない*` を **12〜17秒の6秒間、1枚のまま出しっぱなし**にして、
20〜22秒は**字幕を消している**。

    絵が動く所      → 短く割って畳みかける
    何も起きない所  → 1枚を長く出しっぱなしにする。その退屈さがオチの前振り
    見せ場          → 字幕を消して映像だけにする

**「何も起きない時間」を字幕で埋めないのが、見続けられる理由だった。**

## 折り返しは手で決める

自動で折り返すと「上か／ら狙います」「降りないとい／けません」と
単語の途中で割れて読みにくい。**改行は台本側で `\n` を入れて指定する。**
