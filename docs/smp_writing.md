## 4. 書き方の型が6つある

### ① 括弧 ( ) ＝ツッコミ・心の声・悪態

**これが「面白い字幕」の主力。** アスタリスク *〜* とは役割が違う。

    (どけニート村人)      ← 邪魔な村人への悪態
    (抑えきれない笑い)    ← 声を言葉にしない書き方
    (Wemmbu付き)          ← 最後にぼそっと足す一言

    *アスタリスク*  客観的な状況。「これは実際の声ではない」という印
    (括弧)          編集者のツッコミ。感情が入る

こちらは**アスタリスクしか使っていなかった。**
だから全部が説明文になり、誰の感情も乗らなかった。

### ② たとえる（関係ない状況に喩える）

    *ポケカで数十万レベル引いて指紋すらつけたくない時の反応*

「大事にしている」を「大事にしている」と書かない。
**視聴者が知っている別の場面に置き換える。** ここが一番効いている。

### ③ 名前を付ける

    歩く鉄（鉄ゴーレム）／ニート村人／理論値村人／氷が反社／冷笑系Dream

物や人に**あだ名を付ける。あだ名そのものが笑い。**
「鉄ゴーレム」と書かずに「歩く鉄」と書く。

### ④ 列挙してエスカレートさせる

    超規模監獄 → マグマの壁 → 無限城 → ウォール・マリア
    → 存在しない世界への扉 → 軌道爆撃砲 → 護衛

赤で短く、どんどん大袈裟にしていく。**元ネタの固有名詞**（無限城＝鬼滅、
ウォール・マリア＝進撃）を混ぜる。最後に「護衛」と急に地味なものを置いて落とす。

### ⑤ 敬体で書くとおかしい

    それ相応のセキュリティが必要です
    配信視聴者に見せつけます

くだらない事を**丁寧語で真面目に**書く。この落差が笑いになっている。
「見せる」ではなく「見せつけます」。動詞を1段強くする。

### ⑥ 喋っている素材では、笑いを足さない

クッションの動画は最初から最後まで**ただの翻訳**で、ジョークがゼロ。
本人がずっと喋っているので、字幕が足すと潰し合う。

    喋りが多い素材  → 短く割ってそのまま訳す（クッション）
    喋りが少ない素材 → 括弧とたとえで編集者が喋る（理論値村人・歩く鉄）

**こちらの鉄ゴーレムはセリフが1本しかない＝後者。**
編集者が喋らないと、画面に何も無い時間ができる。

## 5. 色の使い分け（実物から）

    白      地の文・本人のセリフ・括弧のツッコミ
    水色    他プレイヤー、または導入の1行目
    赤      列挙のエスカレート
    黄      上部の固定タイトル
    ピンク  からかい・茶化し（「いっちゃえいっちゃえ♡」）

**ピンクが増えていた。** 前の分析（4色）に入っていなかった。
