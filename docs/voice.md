# 声をどうするか

## いま入っている音

いまの ep02.mp4 には**合成音声**が入っている。エンジンは Open JTalk。
オフラインで動くぶん、正直に言って合成くさい。男性・やや平坦・
語尾がのっぺりする。「聞ける」けど「上手い」ではない。

なぜこれかというと、この作業環境から出られる先が制限されていて、
質のいい読み上げが使えなかったため。実際に試した結果:

| エンジン | 声の質 | この環境で |
| --- | --- | --- |
| Microsoft Edge TTS（ja-JP-Keita / Nanami） | かなり自然。無料 | ❌ `speech.platform.bing.com` が 403 で塞がれている |
| Google 翻訳の読み上げ | 普通 | ❌ `translate.google.com` が 403 |
| Open JTalk | 合成くさい | ✅ 動く（いま使っているのはこれ） |

## 一番いいのは、自分の声で録ること

このチャンネルは「カワウソの先生がタメ口で喋る」のが売りなので、
声が棒読みだとキャラが死ぬ。**自分で喋って録るのが一番効く。**

やること:

1. スマホのボイスメモで、下の台本を**一気に通しで**読む
   （1行ずつ録らなくていい。あとでこちらで切って並べ替える）
2. できたファイルを送る
3. `narration2.wav` として置けば、合成音声より優先して使われる

読むときのコツ:

- 説明ではなく**話しかける**。「〜なんですよ」より「〜やねん」「〜やろ？」
- 疑問形は語尾を上げて、断定は言い切って落とす
- 早口でいい。1行1〜2秒しかない
- 部屋の反響が入るので、布団やカーテンの近くで録る

## ep02 の台本（読む順）

秒数は目安。多少ズレても、こちらでカットに合わせて詰める。

```
 0.0s  bro、飛行機ってなんで飛ぶ？
 2.8s  これ、何百トンある。
 5.0s  それが浮いてる。
 6.8s  学校ではこう習う。
 8.2s  上と下に分かれた空気が、後ろで同時に出会うから浮く、と。
10.6s  でも実際は、上を通った空気のほうが先に着いてしまう。
12.1s  この説明、成り立たない。
13.4s  車の窓から手、出したことある？
15.3s  手のひらを、少し下に傾ける。
16.9s  そうすると、腕が上にぐっと持っていかれる。
18.6s  あれと同じことしてる。
20.0s  翼も、やってることは同じ。
22.0s  翼は、ほんの少しだけ上を向いている。
23.6s  ぶつかった空気は、翼に沿って下へ曲がって出ていく。
26.0s  空気を下に押した分だけ、翼は上に押し返される。
28.4s  空気が下、翼が上。
30.1s  これが揚力。
32.7s  飛行機は、空気を下に殴って進んでる。
34.7s  普通にすごくね？
36.2s  次は電子レンジ。
38.1s  あれ、食べ物を温めてない。
```

`python3 ep02.py --script` でいつでも出せる。台本を直せば自動で追従する。

## 外のサービスを使う手もある

自分で録るのが面倒なら、質のいい読み上げを外で作って
`narration2.wav`（44.1kHz / モノラルでもステレオでも可）として送ってもらえば、
そのまま入る。日本語で使えるところ:

- **VOICEVOX**（無料・ローカルアプリ）… キャラ声が選べる。この用途に一番合う
- **にじボイス / CoeFont**（有料）… 自然さは上
- **Edge TTS**（無料）… 手元のPCなら `pip install edge-tts` で動く。
  `edge-tts --voice ja-JP-KeitaNeural -f script.txt --write-media out.mp3`

## 合成音声の設定を変えたいとき

`voice.py` の `PRESETS` に3つ入っている。聞き比べは:

```
python3 voice.py --demo      # voice_demo.wav（otter / calm / bright の順）
```

| 名前 | 中身 |
| --- | --- |
| `otter` | 少し高く、抑揚を強め（いまの既定） |
| `calm` | 素の声。落ち着いているが平坦 |
| `bright` | かなり高い。子どもっぽくなる |

`voice.build('voice2.wav', preset='calm')` のように指定できる。

## 音のバランス

声が入るときは BGM を自動で **45% 下げている**（`sound.volume_expr(0.55)`）。
声が埋もれるようなら、この数字を下げる。効果音は触っていない。
