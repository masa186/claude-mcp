# 声とクチパク

## 1. VOICEVOX の青山龍星でいきたい件

**この環境からは VOICEVOX を動かせない。** エンジンの配布元（GitHub のリリース）
への通信が組織のポリシーで塞がれていて、403 で弾かれる。塞がれているものは
迂回しない決まりなので、ここは自分の PC でやってもらうしかない。

やることは3分で終わる。

### 手順

1. **VOICEVOX を入れる**（無料）… https://voicevox.hiroshiba.jp/
2. アプリを開いて、**キャラを「青山龍星」にする**（スタイルは「ノーマル」でいい）
3. 画面上部の **「ファイル」→「テキスト読み込み」** で
   `docs/narration_ep02.txt` を読み込む
   → 21行が21個の読み上げ欄になって入る
4. **「ファイル」→「音声書き出し」（全部書き出し）**
   → `001_...wav` のような連番で21個出てくる
5. その21個を **`pipeline/voicevox/` に入れて**、フォルダごと送る

これだけ。あとはこちらで:

- 連番を台詞の順に自動で割り当てる
- 収まらない行はショットのほうを伸ばす（早口にはしない）
- 波形からクチパクを作る

`docs/narration_ep02.txt` と `docs/narration_ep01.txt` は台本を直すたびに
自動で書き出される。中身は1行1台詞、それだけ。VOICEVOX にそのまま入る形。

### 速さの調整

VOICEVOX 側で **話速を 1.0〜1.1** くらいにしておくといい。それより速くすると、
今回と同じで聞き取れなくなる。長くなるぶんはこちらでショットを伸ばすので、
**尺は気にしなくていい**。

### いま入っている声

Open JTalk の合成音声（仮）。合成くさいのは承知の上で、タイミングと
クチパクの動作確認用に入れてある。VOICEVOX の音が来たら即差し替わる。

自分で喋って録るのでもいい。その場合は通しで録って `pipeline/narration2.wav`
（第1話なら `narration.wav`）に置けば、他のどれより優先される。

## 2. ナレーションが速すぎた件 — 直した

原因ははっきりしていて、**尺に収まらない行を早口にしていた**。最大2.6倍まで
上げていたので、そこだけ聞き取れなくなっていた。

早口をやめて、**逆にショットのほうを伸ばす**ようにした。台本の意味を削らずに
済むのはこちら。第2話は 40.1秒 → **45.1秒**。伸ばしたのは10ショット:

```
#06  2.40→3.29秒     #14  1.60→2.28秒
#07  1.50→1.97秒     #15  2.40→2.87秒
#08  1.30→1.76秒     #16  2.40→2.83秒
#09  1.90→2.02秒     #20  2.00→2.30秒
#10  1.60→2.05秒
#11  1.70→2.27秒
```

伸ばした結果 4.2秒を超えるショットが出たら「台本を割ったほうがいい」と
警告が出る。いまは出ていない。

## 3. クチパク — 動いた

### 首の動きについて

原因は、キャラ全体を **±1.4度・4.3秒周期でゆっくり傾けていた処理**。
1枚絵を傾けても生き物には見えず、首だけが動いているように見えていた。
**削除した。**

### クチパクの仕組み（実装済み）

ナレーションの波形から「このコマは口を開けているか」を1コマずつ作る。
決まった速さでパクパクさせると黙っている間も口が動いて気持ち悪いので、
実際に声が出ているところだけ開く。

- しきい値は声の大きさの中央値に自動で合わせる（録り方が変わっても効く）
- 開く／閉じるは最低2コマ続ける（1コマ交互だとチラつく）
- 実測で **毎秒4.1回**、口が開いているのは全体の34%

### 口を開けた絵は、いまある絵から作った

もらった8枚には「口だけが違う組み合わせ」が1つも無かった。
`char_point` と `char_point_open` は名前が対に見えて、実際は**顔の向きも腕も違う
別の絵**（差分が図の85%）。切り替えると口ではなく頭が跳ねる。首の動きより悪い。

そこで絵を調べ直したら、正面向きの5枚
（explain / proud / serious / surprise / blink）は
**どれも同じ顔の上に目と口だけを描き替えたもの**だった。
マズルもヒゲもあごの線も1pxもズレていない。

なので **口のまわりの四角（322,398）〜（608,532）を丸ごと入れ替える**ようにした。
開いた口は `char_arms` から借りている。作者が描いた口をそのまま使うので、
線の太さも色も浮かない。塗りつぶしも描き足しもしていない。

`char_serious` だけ顔が9px右・4px上にズレていたので、貼る前に自動で位置を合わせる。
`char_point` は顔の向きが違うため自動で対象外になる（貼ると破綻するので正しい）。

```
python3 mklips.py --sheet    # 閉じ／開きの見比べを出す
```

書き出されるもの（`mkpng.py` からも自動で呼ばれる）:

```
char_explain_mouth.png   char_proud_mouth.png    char_serious_mouth.png
char_surprise_mouth.png  char_blink_mouth.png
```

### 動いているところ

第2話でクチパクが効く顔アップは5ショット
（surprise ×1 / explain ×2 / proud ×2）。黒板ショットのキャラも同じように動く。

もし**ちゃんと描いた口の絵**を用意できるなら、そのほうがいい。
`render.py` の `MOUTH_FILES` のファイル名を差し替えるだけで入る。
条件は「同じポーズ・同じ大きさ・880×1216・口以外は一切変えない」。

## 4. 音のバランス

声が入るときは BGM を自動で **45% 下げている**（`sound.volume_expr(0.55)`）。
声が埋もれるようなら、この数字を下げる。効果音は触っていない。

現状の測定値: **-16.1 LUFS / ピーク -1.4 dBFS**（TikTok・YouTube にそのまま出せる）。
