# SMPクリップ 36本を実ファイルから全部読んだ（決定版・40本目の分析）

`tools/subs.py` で字幕帯の変化点を自動検出し、1枚残らず切り出して自分で読んだ。

## 道具を2回直した

**① 赤が検出できていなかった。**
輝度で拾っていたが、赤(255,59,48)は輝度116しかなく閾値170で落ちる。
字の色は白・水色・赤・黄・緑・橙どれも「RGBのどれか1色が振り切っている」ので、
**RGBの最大チャンネル**で見るように直した。

**② 字幕の高さが動画ごとに違った。**
固定で63〜77%を見ていたが、実際は**47%のものも72%のものもある**。
固定値で切ると丸ごと取り落とす。
顔カメラも明るくて動くので明るさでは区別できない。
**字は「振り切った明るい点のすぐ横に黒フチがある」**ので、その並びを数えて
帯を自動で探すようにした。肌や空にはこの並びが出ない。

# 1. 【最大の発見】ナレーションは「あらすじ」であって「題名」ではない

`ドクタードーナツ vs Steak`（15.5秒・2,914,482回）── **こちらの鉄ゴーレム14.7秒とほぼ同尺。**

    0.1〜0.8  ドクタードーナツが
    1.0〜1.7  背伸びしてる間に
    1.8〜2.3  倒すという
    2.5〜3.2  steakですが
    3.2〜3.9  数秒後に
    4.0〜4.4  とんでもない
    4.7〜5.5  辿るのでした
    5.5〜9.6  *不発*                    赤・4.1秒
    9.6〜11.7 (下置いても意味ないて..)   水色・2.1秒
    11.9〜15.5 **字幕なし・3.6秒**

つなげると

> **ドクタードーナツが背伸びしてる間に倒すというsteakですが、
> 数秒後にとんでもない〔運命を〕辿るのでした**

**冒頭4.7秒で「オチが来る」ことを予告している。**
「〜のでした」という昔話・ナレーション体。

こちらの鉄ゴーレムは

> マイクラで / 鉄ゴーレムの / 倒し方を / 教える / ドクタードーナツ

で終わっていた。**題名を読み上げただけで、あらすじになっていない。**
「このあと何が起きるか」を一言も言っていない。

**これが「わかりやすい」の正体。** 見ている側は冒頭5秒で
「何を待てばいいか」と「ロクな事にならない」を両方受け取っている。

### 型

    ① 誰が            ドクタードーナツが
    ② 何をしている所に  背伸びしてる間に倒すというsteakですが
    ③ **どうなるか**    数秒後にとんでもない〔…〕辿るのでした   ← ここが抜けていた

3〜7枚、1枚0.3〜0.9秒、尺の最初の25〜30%で言い切る。

# 3. 色は6色。役割ではなく「人」に固定

    白      ナレーション（あらすじの地の文）
    水色    ドクタードーナツ本人
    オレンジ 2人目
    黄      3人目

# 7. 密度は素材の喋りの量で決まる

36本の実測：**0.17〜0.81枚/秒、中央値 0.49。**

25秒以下の7本だけ見ると

    13.5秒  6枚 (0.44)     21.5秒  7枚 (0.33)
    15.5秒 10枚 (0.65)     22.3秒 10枚 (0.45)
    19.0秒  5枚 (0.26)     22.9秒 12枚 (0.52)
    24.3秒  5枚 (0.21)
    → 中央値 **0.44枚/秒**

**14.7秒なら6〜7枚が中央値。10枚で上限。**
こちらの最初の版は21枚（1.43枚/秒）で3倍以上あった。

    喋りが続く素材  0.6〜0.8枚/秒
    静かな素材      0.2〜0.3枚/秒

# 9. こちらの鉄ゴーレムを、この型で書き直す

素材の事実（実測済み）：土の柱→石の斧→殴りかかる→吹っ飛ばされる→
盾→穴掘り→残り1ハート→肉を0.2秒→白い羊毛→逃走→**打ち上げられて落下死**。

    画面タイトル：完璧な作戦（黄・全編固定）

    0.20〜0.75  白    ドクタードーナツが
    0.75〜1.30  白    鉄ゴーレムを
    1.30〜1.85  白    土の柱から
    1.85〜2.40  白    倒すはずが
    2.40〜3.10  白    数秒後に
    3.10〜3.90  白    とんでもない事になります      ← **オチの予告**
    3.90〜4.75  赤    *作戦開始*
    4.75〜5.45  水色  違う、そうじゃない            ← 本人の唯一のセリフ
    5.45〜9.00  赤    *逃げを試みる*                （3.6秒 置きっぱなし）
    9.00〜12.60 赤    *逃げを試みる*                （同じ見出しを繰り返す）
    12.60〜14.00 ──    **字幕なし**（死ぬ瞬間を見せる）
    14.00〜14.70 水色  (…)

**11枚 → 10枚。** 0.68枚/秒。
変えたのは枚数ではなく**中身**：

    ・導入がオチの予告になった（「とんでもない事になります」）
    ・死ぬ瞬間（12.6〜14.0秒）を無字幕にした
    ・最後を「以上、倒し方でした」から「(…)」に変えた
      本家は無言の困惑を括弧だけで書く
