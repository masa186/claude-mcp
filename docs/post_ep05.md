## 説明欄

```
暑い日に冷蔵庫を開けると、冷たい風が出てきます。
じゃあ開けっぱなしにしたら、部屋は涼しくなるのか。

答えは、逆です。部屋は暑くなります。

そもそも冷蔵庫は「冷気」を作っていません。
打ち水で涼しくなるのと同じで、液体が気体になるとき
まわりの熱を奪う。その性質を管の中で起こしています。

管が庫内の熱を拾って、裏側へ運んで、そこで捨てる。
だから冷蔵庫の裏は40〜50度あります。

扉を開けっぱなしにすると、せっかく外へ出した熱が
そのまま同じ部屋に戻ってくるだけ。
おまけに、動かすための電気もすべて熱に変わって足されます。

外に出る熱 ＝ 庫内から取った熱 ＋ 使った電気

部屋の広さや冷蔵庫にもよりますが、1〜3度上がります。

エアコンを部屋の中に置いても、同じことが起きます。

次回はラクダ。あのコブ、水じゃありません。

#冷蔵庫 #雑学 #豆知識 #科学 #shorts
```

## この回で変えたこと（1つだけ）

伸びているショート10本を1本ずつ見せて取った記録（`data/design.md`）で、
決定的な差が見つかった。

**タイトルの約束が回収されるまでの秒数**

```
向こう10本  4 / 11 / 18 / 36 / 42 / 47 / 48 / 48 / 54 / 57   中央値 44.5秒
            40秒以降に回収するものが7本

こちら      飛行機   1.5秒
            電子レンジ 1.8秒
            ペンギン  3.3秒
            冷蔵庫   2.1秒
```

**答えが2秒で出るなら、残る理由がない。**
継続が24〜29%（第2話を除く）だったのはこれが原因だと考えて、
今回は答えを34.2秒まで引っ張った。

タイトルの型も変えた。471本で測ると:

構成も実測に合わせた。説明は3段階（実測で9/10本）、

## 冒頭2秒を作り直した（上位14本の実測）

| | 上位14本 | これまでのうち | 直した第5話 |
|---|---|---|---|
| 一番大きいものの占有 | 中央値 **60%** | 12%（黒板） | 巨大文字が画面で最大 |
| 最初の切り替え | 中央値 **0.8秒** | 1.2〜1.5秒 | **0.8秒** |
| 0〜2秒の文字数 | 中央値 **14文字** | 7〜15文字 | 15文字 |
| 指を止めるもの | **文字の強さ**が最多 | 図と小さい文字 | 巨大文字 |

0秒のフラッシュもやめた。0コマ目が白く飛んで、一番見せたい字が
読めなくなっていた。上位14本は0.0秒の時点で中身がはっきり写っている。

※「占有60%」は Gemini が見た目で答えた割合で、こちらの12%は
背景以外のピクセルの割合。同じ物差しではないので、直接は比べられない。
確かなのは「黒板の冒頭は、画面にほとんど何も無かった」ということ。

## 見るところ

継続率が40%以上に戻れば、原因は「答えを出すのが早すぎた」で確定。
20%台のままなら、引っ張り方以外を探すことになる。
