```
電子レンジのボタンを押すと、食べ物が温まる。
でも、電子レンジが温めているのは食べ物じゃありません。

出ているのはマイクロ波という電波。
これが水と油の分子だけを、1秒に24億回ゆさぶる。
分子どうしがこすれ合って、熱が生まれる。

だからお皿には、その水も油もない。
お皿が熱いのは、食べ物から熱が移っただけです。

次回は冷蔵庫。あれ、冷やしてません。

おまけ：電子レンジが見つかったのは1945年。
```
