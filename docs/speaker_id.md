# 「誰が喋っているか」を測る

Gemini の話者判定は当てにならなかった（秒数も内容も外していた）ので、
音と映像の両方から機械的に割り出す方法を作った。

## 方法

**1. 音の指紋。** 発話区間ごとに周波数の配分を測る。
手元のマイクは近接効果で低音が乗る。配信経由の音は帯域が切られて低音が落ちる。

**2. 顔カメラの動き。** 画面内の顔カメラを1つずつ切り出し、
その区間だけコマ間の差を測る。喋っている人の窓は動く。

**3. 突き合わせる。** 音の群と、動いた窓が一致すれば信頼できる。

## 分かったことと、分からないこと

**分かった。** 声は少なくとも3種類ある。

    群A  低音 11.9〜13.6%  重心 1662〜1773Hz  → 近い声。手元のマイクに近い性質
    群B  低音  4.1〜 5.1%  重心 1964〜2552Hz  → 低音が切れている。配信経由の性質
    群C  低音 20.6〜27.3%  → さらに低音が多い別の声

群Aは3回とも右上の窓が動いていた（2.31〜2.93倍）。**群A＝右上の人**で、
これは確度が高い。

**分からない。** 群Bは左上と右中に割れていて確定できない。
また**それぞれの窓が誰なのかは、こちらでは断定できない。**
顔で見分けるのは間違えたときの被害が大きい（台本に嘘の話者名が入る）。
