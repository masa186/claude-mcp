# みんくら用の素材候補（2026-11-25）

みんくらで当たった3本（千本桜・階段・宝箱）の共通点に合う素材を、最近2か月のマイクラ短尺から探した。

当たった3本の共通点（`docs/minkura_hits3.md`）
- 誰でも知っている物が主役
- その物と、極端な量・主張・反応の差がある
- 答えが1枚の画で分かる
- 20秒前後で終わる
- 前提知識が要らない

**材料と確かさ**
- 候補の選び方：自動サムネイル3枚（Claude が目で読んだ）と題名で24本に絞った
- 中身の読み：うち13本は、Gemini（3-flash と 3.5-flash）に動画を最初から最後まで見せて読ませた（秒ごとの流れ・オチの秒・話している言葉・宣伝かどうか）。`tools/cand_watch.json`
  - **オチの秒は Gemini の読みで、確かめていない**
- 上部タイトル・ナレーション・投稿タイトルの案は、`docs/minkura_template.md` と当たった3本の型で書いた

## 4. 使うときの注意
- **ほかの投稿者の動画**なので、使う前に各投稿者の転載・切り抜きの決まりを確かめ、概要欄に元の動画を書く（今の「本家様のチャンネル」と同じやり方）
- **曲**：8（マライア・キャリー）・9（C418）・4（ボーカル曲）は、著作権の申し立てで収益が取られるか、音が消される可能性がある。曲を差し替えるなら、その動画の雰囲気が変わる
- **宣伝動画**（7・8、たぶん6も）は、訳すと商品の宣伝を代わりにすることになる
- みんくらの今の形は、左上に DrDonut の反応が映るもの。**DrDonut が反応していない素材は、反応無しの形になる**
  - 実写の素材（みんくらの「エンチャントが現実に」4本）は、もともと反応の有無に関係なく伸びていた
- 「N秒後」のナレーションは、**ナレーションが終わる秒＋N秒＝オチの秒**になるように数字を入れる。上の秒は Gemini の読みなので、編集ソフトで確かめてから

## 5. TikTok・Instagram・X を自分で探すなら
- TikTok：検索で「minecraft build」「minecraft hack」「minecraft irl」「minecraft logic」を入れ、フィルターで「いいねが多い順」「今週」
- Instagram：リールで同じ言葉を検索（9月の新ディメンションの話題では、@betweenthepixels_ の投稿が約960万回だった：[Virlo](https://virlo.ai/trending/minecraft-just-broke-a-14-year-silence-and-the-internet-is-losing-it-o)）
- X：「minecraft」で検索し、「話題のツイート」で動画に絞る
- 見つけた動画のリンクをもらえれば、同じ基準（誰でも知っている物・極端な差・1枚の画・20秒前後・前提知識なし）で判定して、3つの文の案を書く
