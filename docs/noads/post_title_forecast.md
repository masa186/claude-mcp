### 1-3. おすすめ

**核爆弾でもレールガンでも消えない笑顔の正体が怖すぎる…**

- みんくらで強い条件を全部満たす（27字・「…」・「正体」・上部タイトルと「核」が重なる）
- 弱い条件（？・結果・末路・名前）を1つも含まない
- 「核爆弾」「レールガン」は、画面の文字（\*宇宙から撃つレールガン\*）と同じ言葉。どんどん大きくなる攻撃を、タイトルだけで伝える
- 「笑顔の正体」：ベリティのニコちゃん顔が、最後に笑った骸骨になる。オチを言わずに、「何かある」とだけ伝える
- 「怖すぎる」：上部タイトルの「絶叫」と同じ方向（最後は怖い）
- 「消えない」：ナレーション「このベリティ以外、全部消えます」と同じ動詞
- 前の案の「核2発」「宇宙レーザー」は、画面の文字と合わない。2発目は TNT の軌道爆撃で、画面の文字は「レールガン」

名前を入れたいとき（ベリティのファン・検索向け）：**核爆弾でもレールガンでも消えないベリティの正体が怖すぎる…**
- みんくらでは名前ありが弱い（0.36）。ただし、ベリティの #59（女の子を襲ったVerityの末路…）は 1.21 だった

## 3. 維持率の見込み

| 数字 | 見込み | 理由 |
|---|---|---|
| **視聴を継続**（スワイプされなかった割合） | **宝箱・階段と同じくらい**（それらの値の ±5ポイント） | スワイプするかは最初の1〜2秒で決まる。最初の2秒の作りが宝箱・階段と同じ。チャンネル初期の1本目（13秒・フックが弱い）は 61.3% だったので、それより上、**70%前後**とみる |
| **平均視聴率** | **60〜75%** | 100万超えの3本（110〜175%）よりずっと低くなるが、尺が2〜4倍なので当たり前。3本の維持率の落ち方（1秒に約2〜3%）を44.6秒に当てはめた |
| 平均視聴時間 | 27〜33秒 | 3本（19〜25秒）より長い。1回あたりの視聴時間は増える |
| 維持率グラフ | 最初の1.5秒で15〜20%減り、そのあとゆっくり下がる。終わりの急な落ちはない（挨拶なし・骸骨で頭に戻る） | 落ちるとすれば、文字のない 19〜23秒（飛んでいる所）と 28〜34秒（暗い画面） |

**公開後に見ること**（半日〜1日）：
1. 視聴を継続が、宝箱・階段より5ポイント以上低くないか（低ければ、最初の1秒の問題）
2. 維持率グラフで、19〜23秒・28〜34秒に段差がないか
3. 最後（43.9秒〜）で、頭に戻って100%を超える所があるか（ループしているか）

## 4. クオリティ

**高い。100万超えの3本と同じ型で、同じ水準。**

- 画面の作り（黒帯のタイトル・左上の顔・白い字幕）が、3本と同じ
- フックが、採点の8項目を全部満たす
- ドクタードーナツの顔が出来事に合わせて動き、最後の骸骨でのけぞる。水色の字幕は本人の英語の正しい訳
- 声：ナレーションは背景より +8dB、ドクタードーナツは話し声の帯域で +10dB。音割れなし
- 文字は全部、画面の安全な範囲（横 16〜82%）に収まっている。最後に黒い画面もない
- 攻撃が大きくなるたびに見出しが出る（核 → 空から核爆撃 → レールガン → 領域展開 → 穴の底 → うぉ！！！）

残っている弱い所は**長さ（44.6秒）**だけ。これは、切らないと決めた代わりに受け入れたもの。

補足：SMP では、TNT を輪の形に並べて落とす仕掛けを「**軌道爆撃砲**」と呼んでいて、7本ある（141万・310万など）。SMP の視聴者には、この言葉で通じる。SMP の「ベリティ vs 軌道爆撃砲」（156万）は別の映像なので、同じ動画の上げ直しには見えない。
