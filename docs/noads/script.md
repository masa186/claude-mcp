**声を入れるときのコツ**
- **ナレーションは2.5〜2.7秒に収める**：話速を上げ、読点の間を短くする（宝箱と同じ長さ）
- **元の音を下げる**：声が鳴っている間だけ、元の音（英語のベリティの声と BGM）を30%くらいに下げる
- **次の声と重ねない**：声が長くて次の声と重なるときは、話速を上げる
  - ベリティの2行目は、元の「待って、ボクを閉じ込めて行っちゃうの？」を短くした（1.7秒に収めるため）
- **オチは元の音のまま**：骸骨（43.9秒〜）には声も文字も重ねず、骸骨の音で終える
