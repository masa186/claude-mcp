# 顔出し無しで、新規チャンネルが伸びているのはどこか（1,205本＋116本）

## 0. 先に、自分の説を撤回する

第7話までで1,200回の天井に2回当たったとき、こう書いた。

> 陰キャの「一番伸びなかった1本」15,154回、こちらの「一番伸びた1本」1,211回。
> これは動画の出来の差ではない。登録21.2万人・707本の履歴があるチャンネルと、
> 登録ほぼ0・8本のチャンネルの差。

**間違いだった。**

反証1：ダンケという人が、新規チャンネルの1本目で68万回・登録+1,256人。
反証2：直近120日の高再生ショート1,205本を、チャンネルの年齢で割ると──

| チャンネルの年齢 | 本数 | 再生中央値 |
|---|---|---|
| 半年未満 | 118 | **2,449,309** |
| 半年〜1年 | 216 | 3,090,258 |
| 1〜3年 | 339 | 2,204,839 |
| 3年以上 | 532 | 2,313,324 |

**年齢はほとんど効いていない。** 登録1,870人で567万回の例もある
（ネタめし・開設80日）。天井の原因は別にある。

## 1. 一番近い比較対象が見つかった

**ジョイ教授の雑学部屋**（開設2026-04-01・約5ヶ月）

    登録 14,300人 ／ 総再生 5,516万回 ／ 116本
    投稿 109日で116本 ＝ 1日1.1本
    **116本すべてが40〜61秒**
    再生中央値 **112,674回**

こちらは8本・最高1,211回。**「普通の1本」で93倍の差がついている。**

### 型が98%固定されている

    「…」で始まる               114 / 116本（98%）
    「〜についての雑学」で終わる   113 / 116本（97%）

    例：「日本でもう一度やってくれ」ミラノ五輪についての雑学

**変えているのは「対象」と「カギ括弧の中の煽り」だけ。**
図も構成も毎回作り直していない。こちらは毎回、図を新規に描いて
構成を組み直している。

### 伸びた12本と、伸びなかった5本

    1,173万  ミラノ五輪
    453万   小泉進次郎
    318万   オリンピックのメダル
    217万   小泉進次郎大臣
    217万   扇千景
    184万   エマ・ワトソン
    ...
    1.5万   国際刑事裁判所ICC赤根智子所長
    1.4万   開成高校のB君
     5,676  お隣の国のサッカー
     4,786  カフェベローチェ
     1,179  コミケ会場近くのローソン

上は全部「名前を知っている対象」、下は全部「知らない対象」に見える。

### ただし、数えたら 1.3倍しかなかった

上下の極端だけを見ると劇的だが、116本全部を機械的に分類すると──

    名前が知られている対象  60本  中央 120,504回
    そうでない対象          56本  中央  89,547回   → **1.3倍**

**極端では効いているが、全体では1.3倍**。
分類が粗い（キーワード一致）せいもあるが、
**「有名なものを扱えば伸びる」と単純化はできない。**
カテゴリーの集計を間違えたときと同じ罠なので、ここは踏まない。

### 確実に言えるのは、ばらつきの大きさ

    最大 11,730,877回 ／ 最小 1,179回 → **9,950倍**

    10万回以上   60本 / 116 = 51.7%
    50万回以上   28本 / 116 = 24.1%
    100万回以上  14本 / 116 = 12.1%
    500万回以上   1本 / 116 =  0.9%

**同じ型・同じ尺・同じチャンネルで1万倍ばらつく。**
当たりは狙って出すものではなく、打席数で拾うもの。
116本打って100万超えが14本。こちらは8本しか打っていない。

## 2. ジャンルごとに、若いチャンネルがどれだけ食い込めているか

直近120日の1,205本。「1年未満のチャンネルの割合」が高いほど新規に開いている。

| 検索語 | 本数 | 1年未満 | 割合 | 再生中央 |
|---|---|---|---|---|
| 雑学 | 40 | 21 | **52%** | 3,442,058 |
| 動物 | 48 | 25 | 52% | 6,586,518 |
| 猫 | 49 | 24 | 49% | 8,030,347 |
| ランキング | 48 | 22 | 46% | **39,969,982** |
| 歴史 | 49 | 22 | 45% | 2,118,854 |
| 事件 | 50 | 22 | 44% | 3,025,821 |
| 心理 | 50 | 16 | 32% | 699,291 |
| 人体 | 50 | 14 | 28% | 115,796 |
| 豆知識 | 41 | 10 | 24% | 1,128,147 |

**雑学は新規に開いている（52%）。** ジャンルを変える必要は無い。

ランキングの中央値は桁違いだが、中身は
`Ranking Amazing Fish Hunting Moments` のような**英語圏の他人の映像の
再編集**で、著作権と「再利用コンテンツ」の問題を抱える。
教材にも「切り抜きだけでは資産になりにくい」とあった。こちらは採らない。

## 4. こちらとの差（測れたものだけ）

| | ジョイ教授 | こちら |
|---|---|---|
| 開設 | 5ヶ月前 | — |
| 本数 | **116本** | 8本 |
| 頻度 | **1日1.1本** | 週1本 |
| 尺 | 40〜61秒（固定） | 23〜84秒（毎回違う） |
| 題名の型 | **98%固定** | 毎回違う |
| 図 | 使い回し | **毎回新規に描く** |
| 再生中央 | **112,674** | 1,211 |

**作り込みの差ではない。** こちらの動画は、ナレーション・構成・図・
テロップ・尺・題名の型を全部測って参考の範囲に入れてある。
差は **本数と、1本にかける時間** のほう。

1本に図を4つ新規に描いて素材を探していたら、1日1本は不可能。
**型を固定して、変えるのは題材と煽りだけにする** のが、
このチャンネルがやっていること。
