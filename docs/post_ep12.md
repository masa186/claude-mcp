詰めたのが効いた。**だが「視聴を継続」は逆に下がっている。**

## タイトル（そのまま貼る）

```

```

**「危ない」側の語を先頭に置く。** 同じ型のチャンネル888本を数えた
ときに一番強かったのが「危ない」系で **3.65倍**、「家・道具」が2.99倍。
これまで見つけた中で単独では最大の差だった。

**数字を題名にも入れる理由。** 陰キャの憧れ707本では数字は0.89倍で
不利だったが、化け学のふしぎ250本では1.78倍で有利だった。
効き方はチャンネルによって逆になる。この回は数字そのものがフックなので、
不利側の集計に合わせて外す判断はしない。

**後半で中身を約束する。** 「やったらあかん入り方3つ」は、
動画が実際に配るものと一致している。「理由」「なぜ」は1.65〜1.77倍と
強い語だが、この動画が渡すのは理由ではなく守りかた3つなので使わない。
題名の約束と中身がずれると、開いた人がその場で落ちる。

## この回で変えたこと

### 1. 0秒に数字を置いた（実写をやめた）

第10話まで、1コマ目は実写を敷いていた。第7話の缶詰（52.7%）は
効いたが、第10話の空と翼（44.0%）は親指サイズで何も言っていなかった。
実写かどうかではなく「1コマ目に情報があるか」だった。

### 2. 締めを冒頭の数字へ返した

ショートは最後まで行くと自動で頭に戻り、**ループぶんも再生時間に
数えられる**。「これだけ覚えといて」では戻る理由が無い。

    この3つだけ
    → 今日、どれかやってへん？
    → 1日52人やからな

最後の「52人」は冒頭の「52人」と同じ数字。頭に戻ったとき、
その数字がもう一度出てくる形にしてある。

40.3秒なら平均0:48で **1.19周**。完走扱いに入る。

### 3. 3選なのに教えが4つあった所を削った

書き出す前の台本には「そのあと急に立ち上がったらあかん」があった。
温度・時間・酒で3つと言っておいて4つ目を混ぜていたので落とした。
