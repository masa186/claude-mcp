# スピード×カイセナットの切り抜きの型（ピクセルから実測）

素材：`Chat Almost Made Kai Cenat & IShowSpeed End A 10 Hour Run`（1,840万回）
28.9秒 / 480×854 / 動き7.01 / 0.69秒perカット / 埋まり32.9%
ラウドネス -10.3 LUFS / レンジ6.4 / 突出6.2%

**これは英語圏の切り抜きチャンネルの完成形で、SMPクリップの元ネタにあたる。**
Geminiに聞いたのではなく、コマを抜いて字幕帯を切り出して読んだ。

---

## 1. いちばん大きい発見

**英語の切り抜きが、SMPクリップとまったく同じ字幕の文法を使っている。**

    白＋太い黒フチ        しゃべった言葉
    *アスタリスクで囲む*   動作・状態（本人が言っていないこと）
    黄色                  別の人物の声。数回だけ

SMPクリップの4色（白＝本人／水色＝他プレイヤー／赤*〜*＝状況／黄＝オチ）は、
**この英語の型を日本語に移したもの**だった。

→ 「SMPクリップの型に流す」＝「英語圏の切り抜きの型に流す」で同じ事をしている。
   本家の素材にそのまま当てはめて違和感が出ないのは、元が同じ文法だから。

---

## 2. 画面の割り付け（Dr Donutの型とは別物）

    縦   0 〜 48%    顔カメラ（カイ）。**画面のほぼ半分**
    縦  43.5〜51%    字幕はこの境目に置く（顔の下端に重ねる）
    縦  48 〜 100%   ゲーム画面

顔とゲームの境目に細い帯がある。

**Dr Donutの型（顔が上25%）と比べて顔が倍ある。**
理由は明白で、**この動画は顔が主役だから。**
ゲーム画面ではポイズンで体力が減っているだけで絵が動かない。
パニックしている顔と叫び声が中身なので、顔に半分渡している。

→ **顔の面積は「どっちが面白いか」で決める。** 固定値ではない。
   鉄ゴーレムは絵が動く（動き9.69）ので顔は小さくていい。

### 終盤でレイアウトが入れ替わる

24.5秒あたりから、**下半分がゲーム画面ではなくスピードの顔カメラ**になる。
最後の2カットはスピードが両手で顔を覆う絵で終わる。

**オチで画面の構成そのものを変えている。** 字幕や音だけでなく、
レイアウトの変更をオチの合図に使っている。これは他の5チャンネルで見ていない手。

## 3. 字幕（切り出して読んだ実物）

| 秒 | 字幕 | 種類 |
|---|---|---|
| 1 | `*EATS*` | 動作 |
| 3 | `*EATS*` | 動作 |
| 5 | `GOD!` | 声 |
| 7 | `NO!` | 声 |
| 9 | `KAI!` | 声 |
| 10.5 | `MILK!` | 声 |
| 11.5 | `MILK!` | 声 |
| 13 | `NO!` | 声 |
| 15 | `HERE!` | **黄色**（別の人物） |
| 17 | `*PANICKING*` | 状態 |
| 19 | `*PANICKING*` | 状態 |
| 21 | `*PANICKING*` | 状態 |
| 23 | `*DRINKS*` | 動作 |
| 24.5 | `THAT` | **黄色** |
| 26 | `F*CK` | 声 |
| 28 | `CHAT` | 声 |

書体：極太、**全部大文字**、太い黒フチ。座布団は使っていない。
位置：顔とゲームの境目、中央寄せ。

### 癖が3つある

**（1）1〜2語しかない。** 最長で `*PANICKING*` の1語。
文を出していない。**文ではなく「札」を出している。**

**（2）同じ札を何度も出しっぱなしにする。**
`*PANICKING*` が17〜21秒の5秒間、`*EATS*` が1〜3秒。
SMPクリップの「3〜6文字で次々切り替える」とは逆で、
**動きが無い区間は同じ札を貼りっぱなしにして間を持たせている。**

**（3）動作と声を印で分ける。**
`*EATS*` は誰も「eats」とは言っていない。編集者が付けた説明。
アスタリスクは**「これは実際の声ではありません」という印**。
これを守っているから、説明を足しても嘘にならない。

→ **こちらの規則「素材に無い台詞を人に喋らせてはいけない」の、
   本家側の解決策がこれ。** 言わせたい説明はアスタリスクで囲めばいい。

## 4. 中身（何が起きているか）

    チャット欄に `altofrenzy: TRY IT` が表示される（Twitchのバッジ付きでそのまま残す）
      ↓
    カイがフグを食べる（*EATS*）
      ↓
    毒で体力が減り続ける（*LOSING HP*）ハードコアの10時間走行中
      ↓
    「GOD!」「NO!」 パニック
      ↓
    「MILK!」 牛乳で毒が消せる
      ↓
    スピードが「HERE!」「(DRINK) THAT」と黄色で叫ぶ
      ↓
    *PANICKING* 5秒間、持ち物欄とかまど画面を行ったり来たり
      ↓
    *DRINKS* 助かる
      ↓
    「F*CK」「CHAT」 チャットに悪態
      ↓
    スピードが顔を覆う（下半分がスピードの顔に切り替わる）

**題名が『チャットのせいで10時間走行が終わりかけた』。**
原因（チャットの一言）を題名に置いて、結果を動画で見せている。

**チャット欄のメッセージを消さずに残しているのが要。**
「なぜこうなったか」が画面の中に証拠として写っている。

## 5. 音

ラウドネス -10.3 LUFS はこちらの第12話（-11）と近いが、
**レンジ6.4・突出6.2%** で、意外と暴れていない。

叫んでいるのに突出が6.2%しかないのは、
**ずっと叫びっぱなしだから**（地の値そのものが高い）。
声の帯を測ると28.9秒中9か所、しかも短い山ばかりで、
静かな区間がほとんど無い。

→ **叫び素材は、こちらで山を作れない。** 元から全部が山なので、
   音で抑揚を付けようとしても効かない。
   **代わりにレイアウトの切り替え（24.5秒）で抑揚を作っている。**

## 6. こちらで使うときの結論

この素材を日本語化するなら：

    題名  チャットの一言でハードコア10時間走行が終わりかけたカイセナット
          （29字。20字以上帯・体言止め・名前が末尾）

    字幕  *フグを食う*  ← アスタリスクは日本語でも残す
          「うわっ」「無理無理」「牛乳！」
          黄色でスピード「これ飲め」
          *パニック* を5秒貼りっぱなし

    尺    28.9秒のまま（20〜29秒帯＝中央値914,983回で最良）

**ただし `F*CK` の扱いに注意。**
26秒の悪態は日本語字幕を付けない。音はそのまま、字幕だけ `*ブチギレ*` にする。
収益化の審査に出す以上、罵倒語を字幕で明文化しない。
