# SMPクリップ 20本を実ファイルから全部読んだ（決定版）

字幕帯の変化点を自動検出して、1枚残らず切り出して自分で読んだ。
`tools/subs.py` がその道具。

## 検出器の不備を1つ直した

最初、明るさ（輝度）で字を拾っていた。
**赤 (255,59,48) は輝度が116しかなく、閾値170で落ちていた。**
字の色は白・水色・赤・黄・緑・橙のどれも「RGBのどれか1色が振り切っている」ので、
**輝度ではなくRGBの最大チャンネル**で見るように直した。
直す前は赤い見出しを丸ごと取り落としていた。

---

## 1. 色は6色あった。役割ではなく「人」に割り当てている

    白      ナレーション（導入の地の文）
    水色    ドクタードーナツ本人のセリフ
    オレンジ 2人目の登場人物（ドロッパー回のFarex）
    黄      3人目（「逝ってらー」）
    **緑**   **固有名詞・他のクリエイター名**（「**Dream**の」の Dream だけ緑）
    赤 *〜*  実況の見出し

前に「白＝本人／水色＝他プレイヤー」と書いていたのは**逆**だった。
緑と橙と黄は存在すら把握できていなかった。

---

## 2. 導入は例外なく同じ形

**一文を3〜6枚に割り、最後を水色の「ドクタードーナツ」で締める。**

    Dreamの(緑) / 空中クラフト / ボート着地に / 挑む → ドクタードーナツ(水色)
    マイクラ / 史上最長の / ジャンプ記録を / 更新する → ドクタードーナツ(水色)
    チートなしで / 鉱石や / 洞窟を / 透視する / 裏技の / 真偽を試す → ドクタードーナツ(水色)
    ドパガキの / 心が / 浄化される / 絶景が
    何かに / 追われてるのを

1枚0.3〜0.9秒。**ここだけ速い。**
YouTubeの題名「〜するドクタードーナツ」を、そのまま字幕で組み立てている。

---

## 3. セリフは「意味」ではなく「音」で書く

これがこちらに完全に欠けていた。

    よーーーーし          伸ばす
    おけい↑?             **矢印で語尾の抑揚**
    おぉッ!//            **スラッシュで途切れ・言い淀み**
    おおおぅっ 待って/
    ふはは…w
    (…?)                 **無言の困惑を括弧だけで**
    無理だろこれwww
    うおおおおお
    ミスったわおい

こちらは「なんだこれ」「よし！」と、**意味を整えて書いていた。**
本家は口から出た音をそのまま写している。

## 4. 赤の *〜* は「実況の見出し」。4つの使い方

    ① あだ名を付ける    *Daquavis御用達コマンド* ← /tick rate 5 のこと
                        *軌道砲発動*  *軌道砲確認*  *トラップドア..*
    ② 心情の見出し      *心の準備*
    ③ **音と気配を指す** *パール音*  *く、*
    ④ 戦術の宣言        *誘導を試みる*
    ⑤ 区切り            *テイク2*  *一時停止*  *2回目の挑戦*

**同じ見出しを繰り返す。** ストーカーは *誘導を試みる* を4回連続。
こちらは「第一の作戦」〜「第六の作戦」と毎回新しく作っていた。逆。

## 5. 【最重要】見せ場では字幕を消す

**こちらのクラッチと同じ素材で本家が作った動画がある。**
`videoplayback_17`（22.3秒）── 尺までほぼ同じ（こちらは22.4秒）。

| 秒 | 本家 | こちらの前の版 |
|---|---|---|
| 0.1〜2.7 | Dreamの / 空中クラフト / ボート着地に / 挑む | *ドリームの* / *伝説のクラッチ* / *落ちながら船を作る* |
| 〜3.0 | ドクタードーナツ（水色） | スコア 0 |
| 3.2〜6.4 | (…?) ← 3.2秒 | 無理やん／*やり直す* |
| 6.5〜8.3 | いや | *もう一回*／*いや待て* |
| 8.4〜8.8 | 無理だろこれwww | *考えてる*／*そして* |
| 8.9〜10.9 | *Daquavis御用達コマンド* | /tick rate 5 |
| **10.9〜21.7** | **字幕なし。10.8秒（尺の48%）** | **11枚びっしり** |

**落下 → 空中でボートをクラフト → 着地。この一番の見せ場で、
本家は10.8秒間まったく字幕を出していない。**

    ストーカー     24.3〜26.7／33.4〜35.4／38.9〜40.6秒

**見続けられる理由は、見せ場で字幕を消しているから。**

## 6. 密度は素材の「喋りの量」で決まる。数字で縛らない

20本の実測：**0.21〜0.83枚/秒。中央値 0.47。**

    videoplayback_9   81.9秒 66枚 0.81  ← 喋りっぱなしの素材
    videoplayback_16  67.2秒 52枚 0.77
    videoplayback_6   25.2秒 15枚 0.60  ← 掛け合いが続く
    videoplayback_17  22.3秒 10枚 0.45  ← こちらのクラッチと同素材
    videoplayback_15  34.2秒 11枚 0.32
    videoplayback_12  24.3秒  5枚 0.21  ← 氷が反社。静かな素材

前に「平均0.36が正しい」と書いたが、**5本しか見ていない小標本の偏り**だった。
20本だと中央値0.47で、上下に4倍の幅がある。

**枚数を決めるのは尺ではなく、素材に喋りがどれだけあるか。**

    喋りっぱなし  0.6〜0.8枚/秒。そのまま短く割って訳す
    静かな素材    0.2〜0.3枚/秒。見出しを置いて、あとは黙る

## 8. こちらが直すこと（優先順）

    1. **見せ場で字幕を消す。** これが一番効く
    2. 導入は一文を割って、最後を水色の「ドクタードーナツ」で締める
    3. セリフは音で書く（よーーーーし／おけい↑?／(…?)／おぉッ!//）
    4. 赤 *〜* は見出し。あだ名を付ける。音を指す。同じ見出しを繰り返す
    5. 色は人に固定。緑は他クリエイター名専用
    6. 枚数は素材の喋りの量で決める。尺で決めない
