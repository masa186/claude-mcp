# 次に何を作るか

## 1. 実測（471本、1日あたり再生数の中央値）

| カテゴリ | 本数 | 中央値/日 | 仕組み比 |
|---|---|---|---|
| 有名人・芸能 | 27 | **21,526** | 13.7倍 |
| 「9割」系 | 36 | **5,708** | 3.6倍 |
| 動物 | 17 | **4,911** | 3.1倍 |
| リスト形式 | 79 | 1,648 | 1.1倍 |
| **仕組み・科学** | 120 | **1,567** | — |
| 実用・お得 | 79 | 310 | 0.2倍 |
| 全体 | 471 | 1,809 | |

うちのジャンル（仕組み・科学）は全体の中央値を下回る。
さらに、うちの実績はそのジャンル中央値の1/3〜1/4:

    第2話 飛行機    1,775回 ÷ 約3日 = 約590回/日
    第1話 電子レンジ  785回 ÷ 2日   = 約390回/日

「有名人・芸能」は13.7倍だが、チャンネルの中身が別物になるので取らない。

## 2. 取るべき組み合わせ

**動物の仕組み × 「9割」の言い方**

- 動物 4,911回/日（3.1倍）。しかもカワウソの先生というキャラと矛盾しない
- 「9割」系 5,708回/日（3.6倍）。これは題材ではなく言い方なので、
  どの題材にも重ねられる
- 実用・お得（310回/日）には寄せない。最下位

動物の実写はフリー素材が豊富にある（Pexels / Pixabay は商用可・
クレジット不要）。飛行機と車しか実写を持っていない問題も、動物なら解決する。

## 3. 「0:02で止まる」の正体

TikTokは両方に「多くの視聴者が0:02で視聴を停止しました」と出している。
継続率のグラフも、2秒で100%→40%台に落ちる。

第2話と第1話で、冒頭2秒の作りが違う:

| | 第2話 飛行機 | 第1話 電子レンジ |
|---|---|---|
| 0秒の画 | **実写の飛行機** | 黒板（暗い） |
| 0秒の文字 | **「9割が勘違いしてる」** | 「電子レンジは温めてない」 |
| 冒頭離脱 | 43.2% | **71.1%** |
| TikTok継続率 | 25% | **18%** |

20本の1コマ目を数えた結果（docs/firstframe.md）:

    背景が実写        13/20本
    明るい            16/20本
    「9割が知らない」系   8/20本（続きを見たくなる要素の1位）

第2話は3つとも満たしていた。第1話は3つとも外していた。
**第1話は、効いていた冒頭の型を捨てていた。** これが冒頭離脱1.6倍の直接の原因。

## 4. 第3話の案

題材は「動物の仕組み」に寄せる。どれも図解アニメで説明でき、実写は
フリー素材で足りる。

| 案 | 0〜2秒 | 根拠 |
|---|---|---|
| **ペンギンの足はなぜ凍らないか** | 氷の上のペンギンの実写＋「9割が知らない」＋一撃音 | 動物3.1倍×9割3.6倍。仕組み（対向流熱交換）は図解向き。冷蔵庫の回とも繋がる |
| カワウソが寝るとき手をつなぐ理由 | ラッコの実写＋「流されへんように」 | キャラ本人の話。動物＋自己言及 |
| 猫が高所から落ちても平気な理由 | 落下スローの実写＋「9割が勘違い」 | 動物。回転の仕組みは図解向き |
| 蚊が自分だけ刺す理由 | 蚊のアップ＋「刺されやすい人の共通点」 | 動物＋自分事。ただし「実用」に寄りすぎない書き方が要る |

**推し：ペンギン。** 動物と仕組みの両方に乗り、図解が作りやすく、
第3話の予告（冷蔵庫）とも熱の話で繋がる。

## 5. 冒頭2秒の作り直し（題材によらず）

1. **0秒は実写**。黒板から始めない（実測13/20が実写、16/20が明るい）
2. **0秒の文字に「9割」系を入れる**。サムネには入れて動画の1コマ目に
   入れていなかった
3. **一撃音**（第2話は impact、第1話は dodon。第2話のほうが強い）
4. 1秒以内に1回切り替える（第1話は1.10秒で切り替えていて、これは維持）

## 6. Gemini の提案で採らなかったもの

Gemini に企画を出させたが、根拠に誤りがあった。

- 「第2話は1,775回でジャンル中央値1,567回を超えている」→ **誤り**。
  1,567は1日あたり、1,775は3日の累計。実際は約590回/日で中央値の1/3。
  「すでに刺さっている」を前提にした案①（飛行機の作り直し）の根拠は崩れる
- 案②④が寄りかかる「実用・お得」は、手元のデータでは310回/日で最下位
- 案⑤（カワウソの手）は実写のカワウソ素材が要り、
  「身の回りの仕組み」からも外れる

採ったのは「ジャンルは変えず、9割の言い方とリスト構成を重ねる」という
方針と、0〜2秒で巨大テロップを先に出すという演出の2つ。

## 7. 第5話（冷蔵庫・答え32秒引っ張り版）の講評を検証

公開直後（エンゲージビュー162、平均視聴0:19、継続30.7%／離脱69.3%）に
Gemini講評（実際の動画を見た体裁）が来た。4点あるうち、台本
（ep05.py）と実写素材を照らして裏を取った。

| 講評の指摘 | 検証結果 |
|---|---|
| 1. 冒頭「どっちと思う？」等の前置きが遅い | ほぼ正しい。実測では3.4秒・4.9秒（講評は0:02・0:04と言うが、フックの0.8秒自体は上位14本の中央値と一致。前置き2ショットぶんが割り込んでいるのは事実） |
| 2. 「庫内/外（裏）」の図解が直感的でない | 正しい。抽象的な四角＋丸ドットのまま。サムネは今回アイコン化したが、**動画本編の図はまだ直していない** |
| 3. fridge2（扉を開けるカット）が海外の業務用ガラス扉に見える | 正しい。1コマ目を見比べ済みで、ロシア語表記（БАТОНЧИК）が写り込んでいる。「家庭用冷蔵庫の質問」と合っていない |
| 4. 相槌（せやのに／ここまではええな）で間延び | 部分的に正しい。合わせて2.8秒の純粋な相槌ショットがある |
| 答えを32秒まで引っ張ったのが遅すぎる、結論ファーストにすべき | **保留**。これは今回の設計判断そのもの（上位10本の中央値44.5秒に合わせた）。162ビュー・平均視聴0:19の1本だけでは、結論ファーストに戻すべきという根拠にはできない（母数が小さすぎる）。当面は変えず、数字が増えてから再検証する |
| セリフ間の無音を完全カット＋ボイス速度1.1〜1.2倍 | **採らない**。声の再現性はLTAS実測でようやく安定させたばかりで、全体速度を上げるとWSOLA再検証が要る。根拠も「一般論として」で実測に基づいていない |

決定（第6話・ラクダから反映。第5話は差し替えない）:
1. 実写は「一目で家庭用と分かるもの」だけを使う。fridge2のような
   業務用ガラス扉クリップは使わない
2. 相槌2ショット（合計2.8秒）を削って尺を締める
3. 答えを引っ張る設計（中央値44.5秒に寄せる）は維持。第5話が伸びる
   かどうかをもう少し見てから判断する
4. 図解を抽象化しすぎない、は継続課題（本編の pump/ 図はまだ手つかず）
