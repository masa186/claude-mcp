## 尺について（初版から修正）

初版で「TikTokの報酬要件に合わせて70秒にする」と書いたが、**優先順位を間違えていた。**

TikTok Creator Rewards は**フォロワー1万人まで1円も発生しない**ので、1分要件はいま効かない。さらにこの要件は**動画ごとの判定**なので、いま40秒で出していても、1万人到達後に70秒で出せばその動画から対象になる。先に短く出しておいて損はしない。

むしろ40秒の方が完走率が高く、制作も速く本数が出せるので、**1万人到達を最優先するなら短い方が合理的。**

**当面は40秒。フォロワー8,000を超えたら70秒に切り替える。**

ただし、下の指摘6つのうち**尺に依存するのは1つだけで、残り5つは40秒でも全部効く。** 特に「一番強い一文がカット3に埋もれている」構成の問題は、尺と無関係に直す価値がある。

## まず、いまの台本の評価

### 効いているところ

- **フックが強い。** 「何を温めてると思う？」は、答えを知っている人でも「水でしょ」と確認したくなる形。指が止まる
- **2枚目で否定から入る。** 「食べ物じゃない」は、正解を言う前に一度突き放していて、続きを見る理由になっている
- **「温めているんじゃなくて、水を暴れさせているだけ」** — 台本で一番強い一文。この言い換えがこの動画の商品
- オチが日常の観察（お皿が熱い）に接続している。ここで「たしかに」が起きる
- 次回予告が「学校で習ったあの説明、実は間違いです」で、単体でフックになっている

### 直すところ

**1. 一番強い一文が、真ん中に埋もれている。**
「水を暴れさせているだけ」がカット3の末尾にある。ここが最後に来るべき。いまの構成だと、一番の決め台詞を言い終わったあと、まだ12秒残っている。**この一文をオチに移動する。** これが構成上の最大の改善点。

**2. カット3が15秒で1枚。長すぎる。**
ショートで同じ絵が15秒静止するのは致命的。ここが離脱ポイントになる。**最長でも1カット12秒、できれば8〜10秒**で割る。

**3. 黒板に図がない。**
`電波 → 水の分子が回転 → 摩擦で発熱` は、文章を矢印でつないだだけ。読ませているのであって、見せていない。**水分子がクルクル回る絵**が要る。これは分かりやすさの問題であると同時に、YouTubeの「編集が最小限」判定を外すための最低ラインでもある。

**4. 数字が埋もれている。**
「一秒間に何十億回」がナレーションの中に流れて消えている。**ここがこの動画で一番の"へえ"**。具体的に「24億回」と言い切って、画面いっぱいに出す。

**5. オチと次回予告が地続き。**
オチの直後に予告が始まるので、余韻がない。**0.5秒空ける。**

**6. 「電波」「摩擦」は突っ込まれる。**
どちらも一般向けの説明としては通用するが、コメントで「マイクロ波では」「摩擦じゃなくて誘電損失では」と来る可能性が高い。対処は2つ、どちらでもいい。

- 逃げる：「電波」→「マイクロ波という電波」、「摩擦」→「ぶつかり合い」に言い換える（下の改訂版はこちら）
- 拾う：来たコメントに「そこに気づく人、強い」と返して**次のネタにする**。`neta_30.md` の運用メモの通り、これが一番おいしい

# 編集手順（CapCut）

## 0. 最初にやる設定

1. 新規プロジェクト → 比率 **9:16**
2. 書き出し設定を先に確認：**1080×1920 / 30fps / 高画質**
3. **セーフエリアを決める。** これが抜けていると全部やり直しになる

| 位置 | 何が乗るか | 対策 |
| --- | --- | --- |
| 上から10% | 各アプリのUI・検索バー | 黒板の文字を上に寄せすぎない |
| 下から20% | キャプション、いいね、シェアボタン | **字幕をここに置かない** |

字幕は**画面の下から25〜35%の高さ**に置く。CapCutの初期位置は低すぎるので、必ず上げる。

---

## 1. 画像を並べて、全部に動きを付ける

7カット分の画像を並べ、台本の秒数に合わせて長さを決める。そのうえで**全カットに必ずズームを入れる。**

- 各画像を選択 → **アニメーション → イン → 「ゆっくりズームイン」**
- または キーフレームで拡大率 100% → 104%（12秒のカットなら104%くらいがちょうどいい）

**これは飾りではなく必須。** 静止画を並べただけの動画は、YouTubeの「編集が最小限のスライドショー」判定に当たる。全カットにゆるい動きがあるだけで外れる。

同じ画像が2回出るカット（解説顔が3回出る）は、**片方を左右反転させるか、ズームの方向を変える**（イン／アウト）。これだけで印象が変わる。

---

## 2. 黒板の文字を乗せる

**画像に文字を描かせない。CapCutのテキストで乗せる。** ここは元の手順通りで正しい。

- フォントは**太めのゴシック**。明朝は縦動画で潰れる
- 色は白〜クリーム（`#EFE9DA`あたり）。純白は黒板の上でギラつく
- 強調する語だけ黄色（`#DFA42B`）
- **一度作ったテキストをコピーして使い回す。** 毎回スタイルを設定しない

**文字は一気に出さない。** 台本で「→」がある箇所は、必ず順番に出す。テキストを別クリップに分けて、開始位置をずらすだけ。

---

## 3. 黒板の図を描く（ここが今回の追加作業）

一番手間だが、**ここが動画の質を決める。** CapCut内で完結する。

### 水分子（カット3）

1. **素材 → 図形 → 円** を3つ置く。大きい円1つ（酸素）＋小さい円2つ（水素）を、上に耳のように配置
2. 3つをまとめて**グループ化**（複数選択 → まとめる）。できなければ、一度この状態で書き出して1枚の画像として取り込む方が早い
3. **回転させる：** クリップを選択 → キーフレーム（◇）をカット頭で打つ → カット末尾に移動 → 回転を`360`にして自動でキーフレームが打たれる → 再生すると1回転する
4. 分子を2〜3個、少しずつ違う速度で回すと「猛烈に回っている」感じが出る

### 氷（カット5）

同じ分子を**格子状に整列させて、動かさない。** カット3で回っていたものが止まっている、という対比だけで説明が終わる。ここは絵で語れる。

### 「24億回」（カット3）

- テキストで画面幅いっぱい
- **アニメーション → イン → 「ポップ」** 系を1つ
- ナレーションが「24億回」と言う**フレームに合わせる**。ここは手で微調整する価値がある

---

## 4. ナレーション

1. **テキスト → テキスト読み上げ**。声は落ち着いた男性か中性的なもの（キャラが先生なので）
2. **速度を1.1〜1.2倍にする。** 標準速度は縦動画には遅い。ここを直すと完走率が変わる
3. **文と文の間の無音を詰める。** 読み上げは文末に余白を作るので、波形を見て0.1〜0.2秒カットする
4. **ただし台本で「間をあける」と書いた3箇所は詰めない**
   - カット1のフックの後（0.3秒）
   - カット5の「じゃあ」の前（0.4秒）
   - カット7のオチの後（0.5秒）

この3つの間が、動画のリズムを作っている。

---

## 5. 字幕

1. **自動字幕**をオン。音を出さずに見る人が7割いる
2. **必ず全部読み直して直す。** 「マイクロ波」「24億回」「分子」はほぼ確実に誤変換する
3. 位置を上げる（セーフエリアの項を参照）
4. 1行が長くなったら手で改行する。2行を超えたら文を切る

---

## 6. 音

- BGMは「フリー」タブから穏やかなもの。**音量20%**（元の手順通り）
- **SEを2つだけ入れる：** カット5の「じゃあ」の直前（章の切り替え）、「24億回」が出る瞬間（ポン、という軽い音）
- SEは入れすぎない。3つ以上入れると安っぽくなる

---

## 7. カットのつなぎ

**トランジションは入れない。** 0.1秒のフェードでも間延びする。全部ストレートカットでいい。

例外はカット4→5の1箇所だけ。ここは章が変わるので、**黒板ワイプか、0.2秒の白フラッシュ**を入れて区切る。

---

## 8. 書き出しと投稿

1. **1080×1920 / 30fps** で書き出す
2. **尺が62秒を超えていることを必ず確認。** TikTok Creator Rewards は1分以上が条件。編集の誤差で59秒になっていたら報酬対象外
3. **CapCutから書き出した元データを3回アップする。** TikTokからダウンロードしたものを転載しない（ロゴが焼き付く）
4. キャプション：「電子レンジ、実は食べ物を温めてません」＋ `#今さら聞けない #雑学 #豆知識`
5. 投稿は夜19〜22時

# カワウソをどう動かすか

## 大原則：キャラより黒板を動かす

視聴者が見ているのは**黒板の文字と図**です。キャラは「いる」ことに意味があって、演技を見られているわけではない。ここを取り違えると、労力が全部キャラに吸われて、肝心の説明が伝わらない動画になります。

**労力の配分は 黒板7 : キャラ3。**

キャラ側の目標は「動いて見える」までで十分で、「アニメーションしている」まで行く必要はない。**呼吸していて、たまにまばたきしていれば、脳が勝手に生きていると判断します。**

一方、黒板側の「動き」は理解に直結するので、ここは削らない：

- 文字が**チョークで書かれていくように**左から現れる（テキストのワイプ系アニメーション）
- 矢印が順番に伸びる
- 分子が回る／止まる
- 数字がドンと出る

順番としては、**黒板の動きを全部やってから、余った時間でキャラを動かす。**

---

## 今週やる3つ（追加コスト0・合計10分）

この3つだけで「静止画を並べただけ」からは完全に抜けます。

### 1. 呼吸（全カットに入れる）

キャラ画像に、2〜3秒周期でごく小さい伸縮をつける。

1. 画像クリップの先頭でキーフレーム → 拡大率 `100%`
2. 1.5秒地点でキーフレーム → 拡大率 `100.8%`、位置を上に `2px`
3. 3秒地点でキーフレーム → 拡大率 `100%` に戻す

**数字を大きくしない。** 1%を超えると呼吸ではなく「膨らんでいる」に見えます。

長いカットで何度もキーフレームを打つのが面倒なら、**3秒分を作ってクリップごとコピーして並べる**方が早い。

### 2. まばたき

目を閉じた画像を1枚生成して、**0.1秒（3フレーム）だけ**差し込む。

- 4〜7秒に1回。**等間隔にしない。** 5秒、7秒、4秒…とばらす
- **0.1秒を超えると不気味になる。** ここは絶対に伸ばさない
- カットの切り替わり直後には置かない（見えない）

これが一番費用対効果が高い。まばたきがあるだけで生き物に見えます。

### 3. カット頭の0.15秒

カットが切り替わる瞬間、キャラを`3px`下からスッと上げる、または`101%`から`100%`に落とす。

人間の目は「動き出し」に反応するので、カットの頭さえ動いていれば、そのあと止まっていても気になりません。**7カット全部に入れて2分。**

---

## 次にやる：表情差分を10枚に増やす

いま5枚（驚き・解説・真面目・ドヤ顔・首かしげ）。**あと5枚足すのが、動かすための一番安い投資です。**

| 追加する差分 | 使いどころ |
| --- | --- |
| 目を閉じている | まばたき（必須） |
| 口を大きく開けている | 強調するとき・驚きの瞬間 |
| ニヤリ（片方の口角） | オチの直前 |
| 汗マーク・困り顔 | 「実は間違いです」系のネタ |
| 腕を組んでいる | 結論を言うとき |

**カットの途中で表情が1回変わるだけで、動画がぐっと生きます。** 12秒のカットなら、7秒あたりで別の表情に切り替える。切り替えはストレートカットでいい。

生成は既存のプロンプトの表情部分を差し替えるだけなので、5枚で10分程度。**一度作れば30本すべてで使い回せます。**

## 指し棒と口パク：やるなら限定的に

### 指し棒

「黒板を指す」動きは解説動画では効きますが、**CapCutの自動切り抜きはイラストだと高確率で失敗します。** 髪の輪郭のない絵は苦手です。

現実的なのは、**指し棒の角度違いをもう1〜2枚生成して切り替える**方法。「上を指す」「中央を指す」「下ろしている」の3枚があれば、黒板のどこを説明していても対応できます。切り抜いてリグを組むより早い。

### 口パク

**72秒フルの口パクはやらないでください。** 手作業だと1本に何時間もかかり、その割に視聴者は気づきません。

やるなら**決め台詞の1文だけ**。「水を暴れさせているだけなんです」のところで、口の開閉2枚を0.15秒ごとに交互に置く。5〜6回切り替えれば十分それらしく見えます。

## 周りを動かして、本体は動かさない

キャラ本体が止まっていても、**周りが動けば動いて見えます。** これが一番安い。

- 驚いたカットで `！` マークを0.2秒ポップさせる
- 集中線をカットの頭に0.3秒
- 「ポン」という効果音に合わせて画面を軽く振動させる（CapCutのエフェクト）
- チョークの粉が落ちる、程度の小さいパーティクル

**1カットに1個まで。** 2個以上入れると一気に子供向けの雰囲気になって、「今さら聞けない」という大人向けのトーンが崩れます。

## AI動画生成（画像→動画）は、いまは使わない

画像1枚から数秒の動画を作るツール（Runway、Kling、Hailuo など）でカワウソを動かすことはできますが、この企画では**現時点で見送り**を勧めます。理由は3つ。

1. **キャラの一貫性が崩れる。** 数秒動かすだけで顔が微妙に変わる。マスター参照画像で苦労して固定したものが壊れます
2. **1本72秒に対して生成は数秒単位。** 十数回生成して、当たりを選んで、つなぐ。時間もコストも合わない
3. **収益化のリスクがむしろ上がる。** AI生成映像を全面に使うと、YouTubeの「非オリジナル・量産」判定に近づきます

使うとしたら、**1本につき1カットだけ**、フックの3秒に限定して。全編には使わない。

## 10話まで続いたら：Live2D

30本作るなら、どこかで**Live2D Cubism**を検討する価値があります。パーツ（目・口・腕・体）を分割してリグを組めば、口パク・まばたき・首の動き・指し棒がすべて自由になり、以降は差分画像を作る必要がなくなります。

- 無料版があるので試すこと自体は0円
- 学習コストは数日。**1話目からやると確実に止まります**
- 判断のタイミングは**10話まで出して、続けると決めたとき**。それまでは上の「呼吸＋まばたき＋表情差分」で足ります

## 所要時間の見込み

| 工程 | 時間 |
| --- | --- |
| 画像の追加生成（1枚） | 5分 |
| 画像を並べる・動きを付ける | 5分 |
| 黒板のテキスト | 10分 |
| **黒板の図（初回のみ）** | **20〜30分** |
| キャラの動き（呼吸・まばたき・カット頭） | 10分 |
| ナレーション・間の調整 | 10分 |
| 字幕の修正 | 5分 |
| 音・書き出し | 5分 |

初回は**1時間強**を見る。ただし図と黒板テキストのスタイルは次回から使い回せるので、**2本目以降は25〜35分**に落ちる。「10分台」は狙わない。狙うと収益化を落とす。

## 2本目以降のために残しておくもの

1. **テキストスタイル** — 黒板文字・強調・数字の3種類をテンプレとして保存
2. **分子の図** — PNGで書き出して素材フォルダに置く。他のネタでも使う
3. **プロジェクトファイルを複製して次の話を作る。** 画像とテキストを差し替えるだけになる
4. **間の位置（3箇所）** — これが型。毎回同じ位置に置く
