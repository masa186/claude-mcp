1. 文字の有無と傾向
*   文字がある：20本（全数）
*   文字数：10〜20文字程度がボリュームゾーン。
*   色：白文字が圧倒的に多く、次いで黄色。
*   フチ・板：20本中18本がフチや背景板を使用しており、文字を視認しやすくする工夫がほぼ必須。

2. 文字の位置
*   上部：13本
*   中央：5本
*   下部：2本
（上部配置が最も一般的）

3. 顔の有無と割合
*   顔が写っている：10本
*   割合：画面の4割〜8割を占めるケースが多く、顔を写す場合は大きく配置する傾向がある。

4. 背景の種類と明るさ
*   背景：実写13本、イラスト・図解7本。
*   明るさ：明るい16本、暗い4本。
（圧倒的に明るい背景が好まれる）

5. 続きを見たくなる要素（多い順）
*   「9割が知らない」「唯一」「10年に1度」などの希少性・意外性を煽るフレーズ：8本
*   視覚的なインパクト（違和感、衝撃的な映像、機械の内部など）：7本
*   疑問形や「〜してみた」などの好奇心を刺激する問いかけ：5本

6. 改善案（効果の大きい順）
*   **「9割が知らない」「実は〜」といった強いフックとなる言葉を文字に入れる**：記録にある伸びている動画の多くが、単なるタイトルではなく「視聴者の知識不足を指摘する」または「強い好奇心を煽る」フレーズを文字として配置しているため。
*   **文字の視認性を高める（背景板の追加）**：黒板（暗い緑）の上に白・黄文字の場合、フチと影があっても背景の明度によっては埋もれる可能性がある。記録の多くが黒い背景板や帯を使用しているため、文字の背面に半透明の黒帯などを敷くことを推奨。
*   **文字の配置を「上部」へ寄せる**：現在の「上寄せ」は記録の傾向と合致しており適切。ただし、画面下半分のカワウソのキャラが文字と被らないよう、文字は可能な限り上端に配置し、中央の図解との間に明確な余白を作ることで視認性が向上する。

※「黒板に白と黄の文字」「カワウソのキャラ」「図解」という構成要素自体は、記録にある「実写＋文字」「イラスト＋文字」の成功例と合致しており、方向性は合っている。
