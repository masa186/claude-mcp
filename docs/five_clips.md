# マイクラ切り抜き5チャンネルの全数分析

`tools/clips.py`（YouTube Data API）で全動画を取り、
`tools/ytask.py` で Gemini に上位動画を直接見せた。
Gemini は YouTube の URL をそのまま読めるので、ダウンロードは要らない。

## 3. 5つの「効いている仕組み」はそれぞれ違う

Gemini に上位動画を1本ずつ見せて出させた。同じジャンルでも中身の作りが違う。

### SMPクリップ ── 技術で驚かせて、笑いで落とす
「20マスジャンプ」は軌道砲という上級技術を見せ、最後は**マヌケな死に方**で落とす。
35秒に「失敗→成功→謎解き→爆死」が入っている。
0:17で不死のトーテムが発動した所に「（…？）」と字幕を出し、
**視聴者と一緒に疑問を持たせて**後半へ引っ張る。

### ドリームクリップ ── 人物の属性を1つに絞り、悪役として売る
「Dreamの友達で唯一道徳がない男」。村人を並べて溶岩の橋にし、
崩れたら助けずに全員射殺する。**一切の慈悲を見せない編集**で
「サイコパス」という一点を最後まで貫く。
神プレイでも感動でもなく、**ヒール（悪役）の魅力**に振り切っている。

### MCトラップクリップ ── 知識とカタルシスの二階建て
「存在しないブロック（ゴーストブロック）」の仕組みを教えてから、実際に敵をハメる。
**視聴者は仕掛けを知っていて、敵は知らない。**
このニヤニヤできる状態を吹き出しで可視化している。
「へぇ〜」と「ざまぁ」を同時に配っている。

### マインクラフトclips ── ルールが一言で分かる企画＋不運の芸
「矢に当たったら鬼」。一言で分かるルールで、
投稿者が何度も鬼になる**天丼（繰り返しの笑い）**を作り、
最後に木の剣で逆転する。1分弱に起承転結が何度も入る。

### MCクリップ ── 音ハメの中毒性
ミーム音声（ベリティ）が喋り終わる前にゲームをクリアしてしまう。
**映像の切り替わりと音が完全に同期していて、リズムだけで最後まで見てしまう。**
「音声素材をいじめる」というストーリーを乗せている。

## 4. 5チャンネル全部に共通している型

1. **上部に固定テロップ。** 全チャンネルが、強い一文を上部に置いて最後まで動かさない。
   「何を待てばいいか」が常に画面にある。
2. **翻訳が自然。** 3チャンネルでGeminiが名指しで褒めた。
   「カモが来た」「にょーん」「のんびりしとく」「無理無理無理」。
   直訳ではなく、日本のネット言葉に置き換えている。
3. **挨拶と間が無い。** 「余計な間が一切ない」。最初の1秒から本題。
4. **短い起承転結を何度も回す。** 30〜50秒に1回ではなく、2〜3回入っている。
5. **効果音が大きい。** 動作に合わせてかなり大きめに置いている。

## 6. Gemini が外したこと

「Dreamというビッグワードを使っているのが伸びた理由」と言ったが、
**ドリームクリップ自身のデータが逆だった。**

    題名にDream  13本  中央値 431,577回
    それ以外     21本  中央値 798,369回   → 名前を出さないほうが1.85倍

人名を題名に出す効果は、チャンネルによって逆転する。

    SMPクリップ        1.42倍（効く）
    MCクリップ          1.48倍（効く）
    ドリームクリップ       0.70倍（逆効果）
    マインクラフトclips    0.40倍（大きく逆効果）

**そのチャンネルの客がその人を知っているかどうかで決まる。**
知られていない名前を出すと、意味の分からない語が題名を占める。

## 7. 取るべき型

新規で始めるなら、**再生が一番大きいSMPクリップではなく、
登録効率が2.2倍で唯一伸びているドリームクリップの型**を採る。

    企画   人物の属性を1つに絞って、そこだけ貫く
           （神プレイでも感動でもなく、悪役・変人・不運などの一点）
    尺     15〜24秒（ドリームクリップの最良帯）
    題名   16字前後。人名は自分の客が知るまで出さない
           ハッシュタグは有っても無くてもいい
    画面   上部に固定の一文。最後まで動かさない
    字幕   直訳しない。日本のネット言葉に置き換える
    構成   挨拶と間を全部切る。30秒に起承転結を2回入れる
    音     動作に合わせて大きめに置く
