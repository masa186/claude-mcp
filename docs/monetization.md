# 収益設計 —「カワウソ先生の黒板解説」

**対象企画：** 縦型ショート「今さら聞けない身の回りの仕組み」（`ep01_script.md` / `neta_30.md`）
**作成：** 2026-08-13

---

## 結論を3行で

1. **再生数報酬は"生活費"にならない。** 月100万再生でも合計3〜10万円。ただし全出口の入口なので回し続ける。
2. **一番早く金になるのはアフィリエイト。** 同じ再生数で、再生数報酬と同額以上が取れる。しかも審査も閾値もない。**今日から仕込める唯一の出口。**
3. **一番単価が高いのは制作代行 → その先の運用代行とBtoB説明動画。** ここに行くために、最初の6ヶ月は「自分のチャンネルの数字」を作る＝営業資料を作っている期間だと考える。

## 先に直すべき3点

出口の話の前に、いまの設計のままだと詰むところが3つある。ここを直さないと出口①が丸ごと消える。

### 1. 40秒だとTikTokの報酬対象外

TikTok Creator Rewards Program は **動画が1分以上であることが参加条件**。台本の「35〜45秒を狙う」は、TikTokの報酬をゼロにする長さ。

| | 現状 | 直した後 |
| --- | --- | --- |
| 尺 | 35〜45秒 | **70〜80秒**（1分ギリギリを狙わない。編集誤差で落ちる） |
| 構成 | 4カット | 6カット（解説パートを2枚増やす） |

構成テンプレの修正案：

| 秒数 | 内容 |
| --- | --- |
| 0〜3秒 | フック。問いを1文 |
| 3〜8秒 | 結論の匂わせ |
| 8〜30秒 | 仕組みの解説（黒板・図） |
| 30〜50秒 | **「じゃあ、なんで◯◯なの？」で1段深掘り** ←追加パート |
| 50〜65秒 | 身近な具体例を1つ（"だからコンビニのアレは〜"） |
| 65〜75秒 | オチ＋次回予告 |

深掘りパートは、ネタ30本のオチをそのまま伸ばせる。例：電子レンジなら「なぜ2.4GHzなのか」「なぜ金属を入れてはいけないのか」。**ネタを増やすのではなく、1本を深くする。**

### 2. Reelsには日本向けの再生数報酬がない

Meta の再生ボーナスは日本未導入、旧 Reels Play は2023年に新規停止、現在は招待制で条件非公開。

**Reelsは収益源ではなく、集客とプロフィール遷移のための場所。** 3プラットフォーム同時投稿はそのまま続けるが、期待値の置き場を変える。

| プラットフォーム | 役割 |
| --- | --- |
| TikTok | 初速・フォロワー獲得・報酬（1分超えれば） |
| YouTube Shorts | 報酬・資産化（過去動画が回り続ける） |
| Instagram Reels | 集客のみ。**プロフィールのリンクが本体** |

### 3. 「画像4枚使い回し＋AI読み上げ」は収益化を弾かれるリスクがある

これが一番大きい。YouTube は2025年7月にYPPポリシーを改訂し、**「大量生産的」「反復的」「非オリジナル」なコンテンツを収益化対象外**と明文化。2026年に入ってAI量産チャンネルの収益化停止が相次いでいる。

判定されやすい特徴と、この企画の現状：

| YouTubeが問題視する要素 | この企画 | 対策 |
| --- | --- | --- |
| 同じテンプレの使い回し | ⚠️ 画像4枚を全話で使い回す前提 | 型は固定でいい。**素材を固定しない**（下記） |
| ナレーションが機械的・変化が少ない | ⚠️ CapCutのAI読み上げ | 読み上げは可。ただし**言い回しのテンプレ化を避ける** |
| 編集が最小限のスライドショー | ⚠️ 静止画4枚を並べるだけ | 黒板の図を毎回描き分ける／文字アニメ／軽いズーム |
| 自動ツールでの一括大量投稿 | — | 1日1本まで。まとめ投稿しない |
| 視聴者に新しい価値がない | ✅ **ここは強い** | 台本が完全オリジナルであることが最大の防御 |

`neta_30.md` の運用メモにある「**同じ構成を崩さない**」は視聴者の認識を作るうえで正しい。矛盾しない切り分けはこう：

> **固定してよいもの** — 構成の型、冒頭2秒の作り、BGM、黒板という舞台、キャラ、声
> **固定してはいけないもの** — 黒板に描く図、カットの構図・表情、ナレーションの言い回し、投稿ペース

最低限やること：**黒板の図を毎回ちゃんと描く。** 文字だけを乗せ替えるのではなく、電子レンジなら水分子、飛行機なら翼と気流の矢印。これがあるだけで「編集が最小限」から外れる。1本あたり10分台という目標は捨てて、20〜30分に置き直す。

## 出口① 再生数報酬

**位置づけ：** 本命ではない。全出口の燃料。

| プラットフォーム | 参加条件 | 単価の目安 | 100万再生あたり |
| --- | --- | --- | --- |
| TikTok Creator Rewards | フォロワー1万＋30日10万再生＋**1分超**＋18歳以上＋個人アカウント | 高い | 4〜10万円 |
| YouTube Shorts (YPP) | 登録1,000＋90日でShorts 1,000万再生（または長尺4,000時間） | 低い | 0.5〜3万円 |
| Instagram Reels | 日本は一般開放なし | — | 0円 |

**試算：** 月30本投稿、1本平均3万再生 = 月90万再生（3プラットフォーム合算）。
このうち報酬対象はTikTokとShortsのみ。現実的な着地は **月2〜8万円**。

数字の意味するところ：

- YouTube側の閾値（90日で1,000万再生）は、**月30本×平均11万再生**が必要。ショートとしてはかなりの当たり具合。半年〜1年見る。
- TikTok側の閾値（フォロワー1万＋30日10万再生）は、はるかに現実的。**3ヶ月で届きうる。**
- つまり **TikTokを先に取りに行く。** そのために尺を70秒にする価値がある。

## 出口② アフィリエイト

**位置づけ：** 一番早く動く。閾値も審査もない。**今週から仕込める。**

### いま何が足りないか

決定的に足りないのは動線。ショートは動画内にリンクが置けないので、経路は1本しかない：

```
動画 → プロフィールへ遷移 → プロフィールのリンク → リンクまとめページ → アフィリンク
```

いまこの経路が存在していないので、どれだけ回っても収益は0のまま。

### 試算

| 段階 | 率 | 月90万再生のとき |
| --- | --- | --- |
| 再生 → プロフィール遷移 | 0.5〜1% | 4,500〜9,000 |
| プロフィール → リンククリック | 20〜30% | 900〜2,700 |
| クリック → 成約（無料体験系） | 2〜5% | 18〜135件 |
| 単価（無料体験系CPA） | 1,000〜1,500円/件 | **2〜20万円** |

再生数報酬と同等以上。しかも**フォロワー1万を待たなくていい。**

### 何を売るか

| 商材 | 単価感 | 相性 |
| --- | --- | --- |
| **Audible / Kindle Unlimited の無料体験** | 高（1件1,000円前後） | ◎ 「知的好奇心」層とほぼ同じ人 |
| 書籍（Amazon/楽天） | 低（料率3%前後＝1冊数十円） | ○ 信頼は作れるが金にならない |
| ガジェット・日用品 | 中 | ○ ネタと直結するものだけ |
| オンライン学習（Udemy等） | 中〜高 | △ 視聴者層とややズレる |

**主力は無料体験系。** 書籍アフィリは「ネタの出典を紹介する」体で信頼を作る役割に置く。

### ネタと商材の紐付け（`neta_30.md` から）

| ネタ | 差せる商材 |
| --- | --- |
| 15. 空の色 / 16. 氷が浮く / 28. 雲 | 科学系の新書・図鑑、Kindle Unlimited |
| 25. 保険 | 保険相談（高単価CPA。ただし信頼を消費するので慎重に） |
| 30. スマホの充電 / 11. Wi-Fi | モバイルバッテリー、ルーター |
| 7. ノイズキャンセリング | イヤホン |
| 12. カイロ / 27. トイレの水 | — （無理に差さない） |

**全部に差さない。** 動画10本に1本、自然に置けるものだけ。ここを焦ると一気に信用を失う。

### 使うASP

- **もしもアフィリエイト** — Amazon の提携が通りやすい。最初はここ
- **A8.net** — 案件数が最大。Audible等
- **楽天アフィリエイト** — 審査なし
- リンクまとめは lit.link などで十分。自前LPは後で

## 出口③ 企業案件

**位置づけ：** フォロワー1万前後から現実的。待つのではなく取りに行く。

### 単価の相場

業界の目安は **フォロワー数 × 2〜6円**。動画は静止画案件の1.5〜2倍。

| フォロワー | 1本あたり |
| --- | --- |
| 1万 | 3〜10万円 |
| 3万 | 10〜25万円 |
| 10万 | 30〜80万円 |

### この企画が有利な理由（＝営業トーク）

「黒板で仕組みを説明する」という形式は、**商品説明に構造の理解が必要な商材**と噛み合う。ここが単価の交渉材料になる。

相性のいい業種：

- 保険・金融（仕組みが分かりにくいのが最大の課題）
- 通信キャリア・プラン説明
- 住宅設備・工法（断熱、給湯、太陽光）
- 家電メーカー（そもそもネタの延長）
- 教育・学習サービス
- BtoBメーカーの採用広報・技術広報

**「PRっぽさが出ない」ことを売る。** 通常のインフルエンサー案件は「使ってみた」だが、この形式は「仕組みを解説する」なので、視聴者の離脱が起きにくい。実際にこれで完走率が落ちないことを数字で示せれば、相場の上限を取りに行ける。

### 取りに行く方法

問い合わせを待たない。フォロワー5,000を超えたあたりから、企業のPR窓口・SNS担当に直接送る。**10社送って1社返れば上出来。**

送るもの（1枚のPDFにまとめる）：
- チャンネルの平均再生数・完走率・視聴者層
- 「御社の◯◯を黒板で解説する」という具体的な絵コンテ1枚
- 過去動画のURL 3本

### ステマ規制（必ず守る）

2023年10月から景品表示法で、広告であることを隠した投稿は違法。**処分対象は広告主だが、規制対応できないクリエイターは単純に案件が来なくなる。**

- 動画内にテロップで「PR」を表示（冒頭から最後まで、または冒頭に明確に）
- キャプションの**冒頭**に `#PR`（末尾に埋もれさせない）
- 各プラットフォームのタイアップ表示機能もオンにする

## 出口④ 制作代行・運用代行

**位置づけ：** 単価が一番高い。ここが本命という認識は正しい。ただし**労働集約なので、階段の上り方を先に決めておく。**

| 段階 | 内容 | 単価 | 労働量 |
| --- | --- | --- | --- |
| 1. 編集代行 | 素材をもらって編集だけ | 3,000〜10,000円/本 | 大 |
| 2. 企画＋台本＋編集 | 丸ごと作る（この企画と同じ工程） | 1〜5万円/本 | 中 |
| 3. 運用代行 | アカウント設計・投稿・分析まで | **月15〜80万円**（月10本前後） | 中 |
| 4. パイプライン販売 | キャラ生成プロンプト＋台本テンプレ＋工程書 | 3,000〜30,000円（買い切り） | **ゼロ** |

### 階段の上り方

**段階1には行かない。** 単価が低く、代替可能で、一番消耗する。いきなり段階2から入る。

入れる理由は、この企画がそのまま**実演販売**になっているから：

- キャラの一貫性を保つ方法（マスター参照画像＋表情差分プロンプト）
- 台本の型（フック→匂わせ→解説→オチ→予告）
- 3プラットフォーム同時展開の運用
- ステマ規制対応

これは「編集ができます」ではなく「**ゼロからチャンネルを立ち上げて回せます**」という提案。単価が一段違う。

### 最初の顧客をどこで取るか

- クラウドワークス / ランサーズ / ココナラ — 初期の実績作り。単価は捨てる
- **X（旧Twitter）で工程を公開しながら直取引** — 手数料ゼロ、単価が高い。本命
- 出口③で接点を持った企業への横展開 — **案件で入った企業に「運用ごと請けます」と提案する。ここが一番決まりやすい**

### 見落とされている高単価：BtoBの説明動画

同じパイプラインで、社内研修・製品説明・採用向けの説明動画が作れる。SNS運用より単価が高く、バズを気にしなくていい（＝再現性がある）。1本10〜50万円のレンジ。

「難しい仕組みを、絵で、短く説明する」という能力そのものが商品。**チャンネルはそのショーケース。**

## 出口⑤ キャラIP・自社商品（追加提案）

挙げられていなかったが、この企画は**キャラを持っている**ぶん有利な出口がある。

- **まず名前を付ける。** 名前のないキャラはIPにならない。「カワウソ先生」でもいい、固有名詞があること自体が重要
- **LINEスタンプ** — 制作コスト実質ゼロ。既存の表情差分がそのまま使える
- **グッズ** — SUZURI等の受注生産なら在庫リスク0
- **note / テンプレ販売** — 「ネタ100本ストック」「キャラ一貫生成プロンプト集」。出口④の段階4と同じ商品
- **書籍化** — 雑学系ショートは書籍化の実績が多いジャンル。初版1万部で印税60〜100万円。これは狙って取るものではなく、フォロワー数万で声がかかる類

## 今週やること

1. **台本の尺を70〜80秒に書き直す。** 第1話を深掘りパート込みで作り直す（TikTokの報酬要件）
2. **キャラに名前を付ける。** 全プラットフォームのアカウント名を統一する
3. **3アカウントを開設し、プロフィールにリンクを置く。** lit.link で1枚作れば十分
4. **もしもアフィリエイトに登録、Amazon提携を申請する。** 審査に数日かかるので先に出す
5. **黒板の図を毎回描く前提に工程を作り替える。** 1本20〜30分に見積もり直す
6. **第1話を3プラットフォームに投稿する。** 温存しない
