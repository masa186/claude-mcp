# SMPクリップの「見る」型 ── 見落としていた一大ジャンル

`Plot twist of the decade` を「本人がプレイしている」と読み違えたのがきっかけで見つけた。
**あれはドクタードーナツが他人の動画を見ている（鑑賞している）動画だった。**

## プレイ動画と見分ける方法（実測）

    9.4秒の画面   HUDが一切ない（ホットバーも体力も照準も無い）
                  その区間だけ上下に黒帯が入る
    0〜8秒の画面  HUDがある

**HUDの有無で「実際にプレイしている画面」か「再生されている映像」かが分かる。**
0〜8秒は他人のクリップ（HUDあり）、8.4秒以降はそのクリップ内の演出カット
（HUDなし・レターボックス）。ドクタードーナツは終始それを見ている側だった。

## 見落としていたこと

前に「〜19秒帯の28本」を全部並べて
**「短尺の最強の型は〈〜するドクタードーナツ〉」**と書いた。その1位が

    3,371,067回 14秒  ドーナツSMPで満足度高い建築を見るドクタードーナツ

だったが、**これがリアクション動画だと気づいていなかった。**
「〜する」の一種として処理していた。

**短尺（〜19秒）の1位は、切り抜きではなくリアクションだった。**

## この型が効く理由

    ・素材を探す仕事が半分になる
      本家のショートをそのまま流して、顔の反応を乗せるだけ
    ・オチが二重になる
      映像のオチ ＋ それを見た人の反応
    ・尺が自由
      14秒から116秒まで全部当たっている

## 台本の組み方（Plot twist に当てはめた実例）

    画面タイトル：落とし物（黄・全編固定・皮肉）

    0.20 白   なくした装備を
    0.85 白   見つけた男の
    1.50 白   とんでもない結末を
    2.15 白   見る
    2.75 水色 ドクタードーナツ          ← 題名をそのまま札に割り、名前で締める
    3.45 赤   *装備を全部拾う*
    5.30 赤   *ネザライトのツルハシ*
    6.00 水色 こいつの装備やん          ← "His armor." 見ている本人の声
    6.70 赤   *持ち主*
    7.70〜12.06 **字幕なし（4.36秒＝尺の36%）**

**9枚 / 12.06秒 ＝ 0.75枚per秒**（52本の実測帯 0.17〜0.91 の中）

### 色の割り当てで気をつけること

リアクション動画は**層が2つある**。

    見ている人   ドクタードーナツ → **水色**
    見られてる人 映像の中の人     → 白・オレンジ・黄

こちらの最初の版は「ドクタードーナツが/なくした装備を/やっと見つけますが」と書いて、
**映像の中の人とドクタードーナツを混同していた。**
拾っているのは別人で、ドクタードーナツはそれを見て「His armor.」と言っているだけ。

## 題名

    今世紀最大のどんでん返しを見るドクタードーナツ            （22字）
    なくした装備を見つけた男の結末を見るドクタードーナツ      （26字）

252本のメタデータでは20字以上が最強（中央値964,294回）。
**「〜を見るドクタードーナツ」は、その形に自然に収まる。**

## こちらの方針への影響

これまで「元素材を探して字幕を付ける」だけをやってきたが、
**リアクションという二本目の柱がある。**

    切り抜き型   本家のショートに日本語字幕を付ける（今やっていること）
    見る型       本家が他人の動画を見ている素材に字幕を付ける

後者は**素材が既に二重構造**（映像＋反応）なので、
字幕が薄くても持つ。実際 Plot twist は9枚で足りた。
