# A. ナレーション（白）── ここが一番の差

## A-1. ナレーションは「題名」ではなく「あらすじ」

`ドクタードーナツ vs Steak`（15.5秒・2,914,482回。**鉄ゴーレム14.7秒とほぼ同尺**）

    0.1  ドクタードーナツが
    1.0  背伸びしてる間に
    1.8  倒すという
    2.5  steakですが
    3.2  数秒後に
    4.0  とんでもない
    4.7  辿るのでした

> **ドクタードーナツが背伸びしてる間に倒すというsteakですが、
> 数秒後にとんでもない〔運命を〕辿るのでした**

**冒頭4.7秒（尺の30%）で「ロクな事にならない」を予告している。**

型は3段。

    ① 誰が          ドクタードーナツが
    ② 何をしている所に  背伸びしてる間に倒すというsteakですが
    ③ **どうなるか**    数秒後にとんでもない…辿るのでした

こちらの鉄ゴーレムは「マイクラで/鉄ゴーレムの/倒し方を/教える/ドクタードーナツ」で、
**③が丸ごと無かった。** 題名を読み上げただけ。

**「〜のでした」「〜します」「〜必要です」の昔話・ナレーション体。**

## A-2. ナレーションは途中でもう一度入る

    〔導入〕という名の / ボコされます
    〔中盤〕これが / 倒す側の

一度で終わらせない。中盤で語り直して、話の向きを変える。

## A-3. 必ず「ドクタードーナツ」が入る

先頭か末尾。末尾に置くときは**水色**（本人の色）にして締める。

    Dreamの(緑) / 空中クラフト / ボート着地に / 挑む / ドクタードーナツ(水色)
    マイクラ / 史上最長の / ジャンプ記録を / 更新する / ドクタードーナツ(水色)
    チートなしで / 鉱石や / 洞窟を / 透視する / 裏技の / 真偽を試す / ドクタードーナツ(水色)

## C-2. アスタリスク無しの赤 ＝ 列挙の項目

`理論値村人`（16.4秒）は**15枚中9枚が列挙**だった。
