## この回で変えたこと

参考チャンネル「無限の机」の全18本を測って決めた（`docs/reference.md`）。

### 1. 失敗を3回入れた ← 一番大きい変更

同じチャンネルの中で、こう割れていた。

| | 10万回/日超（5本） | 1万回/日未満（4本） |
|---|---|---|
| 失敗の回数 | 2〜4回（**5本すべて**） | 0回（**4本すべて**） |

5対0。このデータの中で一番はっきりした差だった。
第1〜5話には失敗が1つも無い。問い→説明→答えで、誰も何も試していない。

この回の失敗:

    19〜26秒  粉のまま燃やしたら、ぼっと燃えて一瞬で終わり
    36〜39秒  棒にしたら40分で消えた。寝てる間もたへん
    45〜51秒  長くしたら自分の重さで折れる。置く場所も無い
    52〜63秒  ヘビのとぐろ → 巻いた → 同じ場所に長い線が収まる

### 2. 尺を48秒 → 77秒にした

これまでの集計は全部「尺60秒以下」で絞っていて、
**一番伸びる帯をまるごと除外していた**。絞りを外して測り直した結果
（10,000回以上・200秒以下・623本）:

| 尺 | 本数 | 中央値/日 |
|---|---|---|
| 30〜45秒 | 127 | 1,218 |
| 45〜60秒 | 207 | 2,686 |
| **60〜90秒** | **142** | **5,634** |
| 120〜200秒 | 35 | 876 |

`#shorts` の明記の有無で割っても、どちらでも 60〜90秒 が最高だった。

### 3. 答えを尺の81%まで引っ張った

第5話は72%。参考4本の中央値は88%。
前回のAI講評は「結論ファーストにしろ」だったが、**採らなかった**。
同じチャンネルの12本で、答えを早く出した4本（12〜55秒）は全部
1万回/日未満、遅く出した5本（37〜107秒）は全部10万回/日超だった。

### 4. 段を8段にした

伸びた5本は平均5.2段、伸びなかった4本は3.75段。

### 5. 図を作り直した

「庫内の四角が箱にしか見えない」（第5話の講評）と同じ失敗をしないよう、
新しい図6つは全部、900×640のキャンバスを使い切る大きさで描いた。
最初に渦巻きを直径218pxで描いたら黒板の上で豆粒になったので、
直径460pxに描き直して、巻き数も実物に寄せて4.5周にした。

図が枠からはみ出していないかを自動で確かめる手順も足した。
このとき `convert('L')` がアルファを無視していて、ほとんど透明な煙を
「はみ出し」と誤検出していた。黒に合成してから測るように直した。
